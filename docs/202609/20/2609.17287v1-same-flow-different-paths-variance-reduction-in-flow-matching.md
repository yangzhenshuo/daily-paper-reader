## 摘要
在流匹配（FM）中，速度模型 $v_θ$ 使用预定义路径 $g_t$ 进行训练，该路径连接数据样本和噪声样本（例如，$g_t(x_0, x_1) = (1 - t) x_0 + t x_1$）。在这项工作中，我们从优化角度研究该路径的选择，通过分析随机梯度的方差。我们考虑路径类 $G(p_t,v^\star_t)$，这些路径诱导相同的边缘分布 $p_t$ 和边缘速度场 $v^\star_t$，因此对应相同的 FM 目标。我们的主要发现是，即使 FM 目标完全相同，路径 $g_t$ 的选择也会从根本上改变 SGD 的收敛速度。（i）对于线性速度模型和一维高斯数据，我们推导出 SGD 迭代复杂度的紧致界（至多对数因子），并找到一个解析最优路径，该路径在诱导相同 FM 问题的线性路径中最小化该界。（ii）随后，我们将方差分析推广到一般 FM 问题，并将固定 $θ$ 下的路径选择形式化为方差最小化问题 PathOpt$_θ$，约束为 $g_t\in G(p_t,v^\star_t)$。我们表明该约束至关重要：不施加该约束而降低方差可能导致收敛变慢。（iii）由于约束 $g_t \in G(p_t,v^\star_t)$ 通常无法直接验证，我们推导出一个等价形式，其中的约束可以从样本中估计，从而能够通过数值方法找到路径。我们的理论结果得到了高斯数据、高斯混合模型和真实数据集实验的支持。

## Abstract
In flow matching (FM), a velocity model $v_θ$ is trained using a predefined path $g_t$ that connects data and noise samples (e.g., $g_t(x_0, x_1) = (1 - t) x_0 + t x_1$). In this work, we study the choice of this path from an optimization perspective by analyzing the variance of stochastic gradients. We consider the class $G(p_t,v^\star_t)$ of paths that induce the same marginal distributions $p_t$ and marginal velocity field $v^\star_t$, and therefore the same FM objective. Our main finding is that the choice of path $g_t$ can fundamentally change the convergence rate of SGD, even when the FM objective remains exactly the same. (i) For a linear velocity model and one-dimensional Gaussian data, we derive a tight bound on the SGD iteration complexity up to logarithmic factors and find an analytically optimal path that minimizes this bound among linear paths inducing the same FM problem. (ii) We then extend the variance analysis to general FM problems and formulate path selection at a fixed $θ$ as the variance-minimization problem PathOpt$_θ$, constrained to $g_t\in G(p_t,v^\star_t)$. We show that this constraint is essential: reducing variance without it can lead to slower convergence. (iii) Since the constraint $g_t \in G(p_t,v^\star_t)$ cannot generally be verified directly, we derive an equivalent formulation with constraints that can be estimated from samples, allowing paths to be found numerically. Our theoretical results are supported by experiments with Gaussian data, Gaussian mixture models, and real datasets.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：流匹配（Flow Matching, FM）是当前图像/视频生成的主流方法之一（如 Stable Diffusion 3、Wan 等）。其训练目标是让速度模型 $v_\theta$ 拟合一条预定义路径 $g_t$ 上的速度场，典型路径为直线路径 $g_t(x_0,x_1)=(1-t)x_0+tx_1$ 或余弦路径。
- **核心问题**：在 FM 中，给定同一对边缘分布 $(p_t, v^\star_t)$，存在**多条路径** $g_t$ 都能诱导出完全相同的 FM 目标 $L_{\text{FM}}$。以往研究多关注路径的"非优化"性质（能否学到正确的速度场），而忽略了**路径选择对优化过程本身的影响**。
- **关键洞察**：虽然目标函数相同，但随机梯度 $\nabla L_{\text{CFM}}(\theta;\xi)$ 依赖路径 $g_t$，因此**不同路径的梯度方差不同**，进而导致 SGD 收敛速度的根本差异。
- **整体意义**：论文首次系统地从优化视角研究 FM 路径设计，提出"在保持 FM 问题不变的前提下，通过选择低方差路径来加速 SGD 收敛"，为路径设计提供了理论基础。

## 2. 方法论

### 2.1 核心思想：约束方差最小化

- 定义路径集合 $G(p_t, v^\star_t)$：所有诱导相同边缘分布 $p_t$ 与边缘速度场 $v^\star_t$ 的路径。
- 随机梯度方差分解为两部分：
  - $\text{Var}_1(\theta; p_t, v^\star_t)$：与路径无关（仅依赖 $p_t, v^\star_t$）；
  - $\text{Var}_2(\theta; g_t)$：与路径相关，是优化的关键。
- 在最优参数 $\theta^\star$ 处 $\text{Var}_1=0$，因此核心问题是**在 $G(p_t, v^\star_t)$ 内最小化 $\text{Var}_2$**。

### 2.2 线性模型 + 一维高斯：解析最优路径

- 设定：$v_\theta(x,t)=\theta x$，$p_{\text{data}}=\mathcal{N}(0,\sigma^2)$，线性路径 $g_t=a_t x_0+b_t x_1$。
- **Proposition 2.1**：FM 问题可解（存在 $\theta^\star$ 使 $L_{\text{FM}}(\theta^\star)=0$）当且仅当 $q_t:=\sigma^2 a_t^2+b_t^2=\sigma^{2(1-t)}$，且此时 $\theta^\star=-\log\sigma$。
- **Theorem 2.2**：SGD 迭代复杂度紧致界（上下界匹配至对数因子）：
$$T_{\text{SGD}}(a_t,b_t)=\frac{\mathbb{E}_t[q_t^2]}{(\mathbb{E}_t[q_t])^2}+\frac{\mathbb{E}_t[\sigma^2(a_t\dot b_t-b_t\dot a_t)^2]}{(\mathbb{E}_t[q_t])^2\varepsilon}$$
- **Proposition 2.3**：用极坐标 + Euler–Lagrange 方程求解，得到解析最优路径：
$$a^\star_t=\sigma^{-t}\cos\!\Big(\tfrac{\pi}{2}\tfrac{\sigma^{4t}-1}{\sigma^4-1}\Big),\quad b^\star_t=\sigma^{1-t}\sin\!\Big(\tfrac{\pi}{2}\tfrac{\sigma^{4t}-1}{\sigma^4-1}\Big)$$
- **对比**：朴素路径 $\bar a_t=\sigma^{-t}\cos(\pi t/2),\bar b_t=\sigma^{1-t}\sin(\pi t/2)$ 的复杂度为 $\tilde\Theta(1/\varepsilon)$，而最优路径在大 $\sigma$ 时为 $\tilde\Theta(1/(\sigma^4\varepsilon))$，显著加速。

### 2.3 一般 FM 理论：PathOpt 问题

- 提出两个一般化问题：
  - $\text{PATH OPT}^{\max}_{\Theta}$：$\min_{g_t\in G(p_t,v^\star_t)}\max_{\theta\in\Theta}\text{Var}(\theta;g_t)$
  - $\text{PATH OPT}_\theta$：固定 $\theta$ 时最小化 $\text{Var}(\theta;g_t)$，等价于最小化 $\mathbb{E}[\|J_\theta(x_t,t)^\top\dot g_t\|^2]$
- **约束必要性（Example 3.1）**：构造病态路径 $g^M_t=e^{-Mt(1-t)}(\cos(\pi t/2)x_0+\sin(\pi t/2)x_1)$，当 $M\to\infty$ 时方差 $\to 0$，但迭代复杂度 $\to\infty$。说明**不施加 $g_t\in G(p_t,v^\star_t)$ 约束，降方差反而会拖慢收敛**。

### 2.4 可行化：Feasible PathOpt

- 由于 $p_t, v^\star_t$ 未知，约束无法直接验证。引入参考路径 $\bar g_t$，用两个可采样估计的度量替代约束：
  - **能量距离** $D^2_{p,t}(g_t,\bar g_t)$（Proposition 4.1）：$=0 \Leftrightarrow g_t\overset{d}{=}\bar g_t$
  - **核速度差异** $D^2_{v,t}(g_t,\bar g_t)$（Proposition 4.2，基于高斯核）：$=0 \Leftrightarrow v^\star_t=\bar v^\star_t$（在 $p_t=\bar p_t$ 下）
- **Theorem 4.3**：$\text{PATH OPT}_\theta$ 等价于带上述两个期望约束的可行问题 $\text{FEASIBLE PATH OPT}_\theta$，可用随机优化或网格搜索求解。
- **算法 1**：原始-对偶随机优化方案（primal 用 Adam 更新路径参数，dual 用投影梯度更新乘子 $\lambda_p,\lambda_v$）。

### 2.5 与时间采样的联系

- 时间分布 $\rho(t)$ 的重要性采样也可降方差，最优 $\rho^\star(t)\propto\sqrt{S_{\theta,g}(t)}$。
- **Section G.1 结论**：在线性高斯例子中，时间采样相对路径优化仅带来 $O(\log\sigma^2)$ 的提升，**路径优化是主导因素**，二者互补可联合优化。

## 6. 主要结论与发现

1. **路径选择可根本改变 SGD 收敛率**，即使 FM 目标 $L_{\text{FM}}$ 完全相同。
2. 在线性高斯情形下，推导出**紧致的上下界**和**解析最优路径**，最优路径在大 $\sigma$ 时复杂度从 $\tilde\Theta(1/\varepsilon)$ 降至 $\tilde\Theta(1/(\sigma^4\varepsilon))$。
3. **约束 $g_t\in G(p_t,v^\star_t)$ 不可省略**：无约束降方差会改变 FM 任务，导致更慢收敛（病态例子中方差 $\to 0$ 但复杂度 $\to\infty$）。
4. 提出可用样本估计的等价约束（能量距离 + 核速度差异），使路径可数值求解。
5. 时间采样优化相对路径优化仅带来对数级提升，路径优化是主导。
6. 实验验证：学习路径的梯度方差显著低于朴素路径（如 $\sigma=6$ 时 120.73 vs 1783.32），GMM 与真实数据上生成质量均有提升（SVHN FID 从 13.596 降至 10.282）。

## 7. 优点

- **理论严谨**：给出匹配的上下界（至对数因子），最优路径有闭式解，论证充分。
- **问题视角新颖**：首次聚焦"FM 表示的非唯一性"这一自由度，而非路径的传输性质，开辟了路径设计的新维度。
- **约束处理巧妙**：用能量距离和 RKHS 核方法将不可验证的分布/速度场等式约束转化为可采样估计的可行约束，具有实用价值。
- **理论-实验闭环**：从解析最优路径到学习路径的数值逼近，再到 GMM 和真实数据，逐层验证，逻辑完整。
- **约束必要性论证有力**：病态例子 + 无约束消融实验双重支撑，警示性强。
- **与时间采样的关系分析**：明确了两类方差缩减手段的相对贡献，避免重复劳动。

## 8. 不足与局限

- **理论保证范围有限**：仅在**一维高斯 + 线性模型**下建立了严格改进的收敛率；GMM 与非线性模型只有方差分析，无端到端复杂度保证。
- **$\text{PATH OPT}_\theta$ 只是代理目标**：它仅对应收敛上界中的方差项，未考虑平滑性、曲率等损失几何因素，与实际端到端训练复杂度可能不完全一致。
- **非凸优化困难**：$\text{FEASIBLE PATH OPT}_\theta$ 的约束优化是非凸的，精确满足约束和全局最优难以保证；实践中需网格搜索或启发式调参（如 $\delta$ 阈值、核带宽 $h$）。
- **真实数据提升有限**：路径族参数少（$m=2$），FID 改善幅度小，部分数据集（Flowers-102）无提升，AFHQ-Cat 提升不显著；作者也承认需学习更大规模、能适配网络权重与优化器状态的路径模型。
- **未与其他方差缩减方法直接对比**：如 Multisample FM、Optimal Transport coupling、Stable Velocity 等，缺乏横向 benchmark。
- **算力报告不完整**：未给出总 GPU 小时或路径搜索阶段的开销，复现成本不明确。
- **实验覆盖偏差风险**：真实数据集的路径选择基于在初始化和最终 checkpoint 处的方差评估，可能对特定训练阶段过拟合；GMM 实验仅在 1D 上进行。
