## 摘要
近年来，视觉-语言-动作模型（VLA）将大语言模型（LLM）的语义理解与流匹配策略的精确控制相结合，改变了机器人操作领域。优势条件化是一种近期技术，它通过在部署数据上训练价值函数，并利用该函数训练优势条件化策略，从而迭代地改进VLA。先前的工作仅使用了简单、低信息量的成功/失败奖励，这使得价值函数除了任务表面上的推进程度外，无法区分质量不同的状态。受对分布外（OOD）检测方法的探索启发，我们提出了基于距离的优势学习（DistAL），它通过使用嵌入空间距离作为奖励，产生信息量更丰富的价值函数，并进而带来更高的下游任务成功率。我们在系列仿真基准以及真实硬件上的灵巧双臂操作任务中验证了我们的方法。

## Abstract
Vision-language-action models (VLAs) have trans- formed the field of robotic manipulation in recent years by combining the semantic understanding of LLMs with the precise control of flow-matching policies. Advantage conditioning is a recent technique that iteratively improves VLAs by training a value function on deployment data and using this to train an advantage-conditioned policy. Previous works have only applied simple, low-information success/failure rewards, which leave the value function unable to distinguish states of differing quality beyond how far along the task they appear. Motivated by an exploration of out-of-distribution (OOD) detection methods, we introduce Distance-based Advantage Learning (DistAL), which, by using an embedding space distance as a reward, produces a more informative value function and subsequently a higher downstream task success rate. We validate our method on a series of simulation benchmarks and dexterous bi-manual manipulation tasks on real hardware.

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言-动作模型（VLA）结合 LLM 语义理解与流匹配策略的连续动作生成能力，已显著提升机器人操作性能。但接触丰富、灵巧操作任务中，策略仍难以达到真实部署所需成功率。
- **现有改进路径的问题**：
  - 人类干预数据：需要专家操作员全程待命，硬件与运营复杂。
  - 在线强化学习微调：样本效率低、不稳定、计算成本高。
  - 优势条件化（advantage conditioning）：作为离线 RL 式方法，利用部署数据训练价值函数，再训练优势条件策略，避免干预和在线 RL 的不稳定。
- **核心痛点**：已有优势条件化工作仅使用成功/失败二值奖励。其价值函数主要按“任务推进到哪一步”排序状态，无法区分同样接近完成但质量不同的状态，例如稳定抓取与勉强抓取。自定义任务奖励又难以扩展。
- **论文含义**：作者提出 **DistAL（Distance-based Advantage Learning）**，用嵌入空间距离作为密集奖励，替代稀疏成功/失败奖励。核心假设是：失败轨迹相对成功参考数据更可能是分布外（OOD）。因此，到基础 VLA 训练分布的 kNN 距离可作为每步质量信号，产生更有信息的价值函数，并提升下游优势条件策略成功率。

## 2. 方法论

- **核心思想**：
  - 不改变优势条件化主流程，只替换奖励信号。
  - 使用基础 VLA 训练数据在 SigLIP 特征空间中的 kNN 距离，作为部署观测的每步奖励。
  - 距离越近表示越接近训练分布，奖励越高；距离越远表示越可能偏离正常/成功状态，奖励越低。

- **kNN 特征距离奖励**：
  - 设冻结图像编码器为 \(f: O \to \mathbb{R}^{d_f}\)，基础 VLA 训练集观测嵌入索引为 \(I=\{f(o^{(i)})\}_{i=1}^N\)。
  - 对部署观测 \(o\)，计算其到训练分布嵌入的 k 近邻平均欧氏距离：
    \[
    s_k(o)=\frac{1}{k}\sum_{j\in N_k(f(o);I)}\|f(o)-z_j\|_2
    \]
  - 每步奖励取负距离：
    \[
    r_t=-s_k(o_t)
    \]
    并归一化到 \([-1,0]\)。
  - 关键假设：越接近基础 VLA 训练分布的状态越好。但该假设并非普适，因此保留失败回合的大终端惩罚，避免策略仅靠停留在熟悉早期状态获得高奖励。
  - 论文使用 \(k=10\)，称任务成功对 k 不敏感；编码器不是原始 SigLIP，而是基础 VLA 微调后的 SigLIP 视觉编码器。

- **价值函数与优势标签**：
  - 使用蒙特卡洛回报：
    \[
    G_t=\sum_{k=0}^{T-t} r_{t+k}
    \]
  - 价值函数 \(V_\phi\) 通过回归/分类方式拟合 \(G_t\)。架构为预训练 Gemma3 270M 语言模型 + 400M SigLIP 视觉编码器，最后接 2 层 MLP 头。
  - 不直接回归连续值，而是预测离散回报分箱上的类别分布，用交叉熵训练；尝试 HL-Gauss 损失但无额外收益。
  - 优势估计：
    \[
    \hat A_t=G_t-V_\phi(o_t)
    \]
  - 优势标签：
    \[
    y_t=\mathbb{1}[\hat A_t>\kappa]
    \]
    阈值 \(\kappa\) 设置使约 30% 标签为正。

- **优势条件策略与训练流程**：
  - 基础策略为微调后的 \(\pi_{0.5}\)，包含 PaliGemma 3B VLM 与 300M 流匹配动作专家。
  - 将二值优势标签以文本形式追加到语言输入中，如 “Advantage: positive” 或 “Advantage: negative”；无条件时追加空标记。
  - 训练时仅微调动作专家，冻结 VLM 主干，效果最好。
  - 推理时使用分类器无引导：
    \[
    \tilde v_\theta(a_\tau,\tau,c,y=1)=v_\theta(a_\tau,\tau,c,\varnothing)+w\cdot(v_\theta(a_\tau,\tau,c,y=1)-v_\theta(a_\tau,\tau,c,\varnothing))
    \]
    其中 \(w>1\) 引导策略朝正优势动作生成。
  - 训练三步：
    1. 用 kNN 距离给部署观测打奖励。
    2. 拟合价值函数并生成优势标签。
    3. 用优势标签微调 VLA，训练时以概率 \(p\) 丢弃标签。

## 3. 实验设计

- **OOD 检测作为失败预测器实验**：
  - 在 LIBERO、LIBERO-plus 以及两个真实双臂硬件任务上，采集基础 \(\pi_{0.5}\) 策略 rollout，并标注成功/失败。
  - 比较 5 种检测器：
    1. kNN – SigLIP 特征（LM 前），即论文方法。
    2. kNN – LM 图像输出 token（LM 后）。
    3. Mahalanobis – SigLIP 特征。
    4. VAE 似然。
    5. 动作块方差：同一上下文下 16 次流匹配采样动作的标准差。
  - 指标：轨迹级 AUROC 与每步级 AUROC，随机为 0.5，越高越好。

- **仿真实验**：
  - 数据集/基准：
    - LIBERO-10，即 LIBERO-Long，LIBERO-100 中十个长时程任务。
    - LIBERO-plus，按扰动类型报告：Layout、Camera、Light、Init.、Noise、Lang.、Texture。
    - 未使用 LIBERO-Spatial、Object、Goal，因 \(\pi_{0.5}\) 已饱和，无提升空间。
  - 部署数据：每个任务收集 50 条 rollout，带成功/失败标签。
  - 对比方法：
    1. Base \(\pi_{0.5}\)。
    2. SFT：只用成功轨迹继续微调。
    3. RECAP-style binary reward：相同优势条件化流程，但用稀疏成功/失败奖励。
    4. DistAL：用 kNN 距离密集奖励。
  - 所有优势条件化方法使用相同部署数据集，隔离奖励函数影响。
  - 报告 3 个随机种子，每个任务 50 个 episode 的平均成功率。

- **真实硬件实验**：
  - 平台：双臂 Piper 机械臂，每臂腕部相机 + 外部场景相机。
  - 任务：
    - remove pen lid：一臂稳定笔身，另一臂抓取并拔下笔帽。
    - remove ethernet cable：一臂固定端口，另一臂抓取并拔出网线。
  - 每个任务收集 50 条遥操作示范微调基础 \(\pi_{0.5}\)，再收集 50 条部署 rollout 形成 \(D_{\text{deploy}}\)。
  - 对比：Base \(\pi_{0.5}\)、RECAP-style binary reward、DistAL。
  - 每个任务评估 50 次 rollout。
