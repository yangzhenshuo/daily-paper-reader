## Abstract 

Stopgrads are widely used in training machine learning models, but stopgrads can alter the gradient, stationary points and convergence guarantees of the orig-inal objective, which can make stopgrad training theoretically ungrounded. We introduce a stopgrad regression principle , which identifies a general template for stopgrad objectives with a closed-form characterization of stationary points and their uniqueness, unifying stopgrad objectives for flow maps, reinforcement learning, and diffusion samplers. We provide theoretical grounding for optimizing stopgrad flow map objectives by showing their unique stationary point is the true flow map, and showing positive convergence results for Eulerian and Lagrangian objectives, including MeanFlow and improved MeanFlow. Remarkably, we show that under functional semi-gradient flow, the learned flow map has a closed-form expression composing the initial flow map and the true flow map. We additionally use our stopgrad regression principle to propose modified stopgrad placements for flow map objectives which reduce training memory by 2×.

## 1 Introduction 

Stop gradients ( stopgrad ) are a basic primitive in automatic differentiation packages like PyTorch and JAX. Stopgrads leave the forward pass unchanged, but in the backward pass, they return a zero gradient and block further gradient propagation. Stopgrads are widely used in machine learning, including in self-referential objectives where a model is supervised in terms of itself, as in self-distillation, reinforcement learning ( RL ) [43], consistency models and flow maps [41, 15], representation learning [33], as well as variational inference [35, 45]. For example, in RL , popular algorithms such as temporal-difference learning and actor-critic methods rely on stopgrads in practice [29, 25, 39, 42]. However, stopgrad objectives update models with semi-gradients (differentiating only some occur-rences of the model), which are not the gradient of the original objective [42]. Semi-gradient update fields may be non-conservative, meaning they may not be the gradient of any objective, and updates could follow a loop indefinitely without making progress. Whereas standard gradient descent is akin to marching through mountains and valleys, optimizing stopgrad objectives can be like wandering in Escher landscapes (Fig. 1). These concerns motivate understanding stopgrad optimization theory, which seeks to understand the stationary points and convergence of stopgrad objectives. Recently, stopgrads have featured prominently in methods for training flow maps , which learn to integrate probability-flow ODEs in few steps [41, 40, 28, 21, 37, 8, 36]. MeanFlow [15] introduced a stopgrad objective but did not analyze its stationary points or convergence. Boffi et al. [8, 9] introduced the Eulerian self-distillation ( ESD ) and Lagrangian self-distillation ( LSD ) objectives and

## 3 Stopgrad Regression Principle 

Here, we present a unifying stopgrad regression principle. This principle identifies a general template for stopgrad objectives where the learned function appears in only one term outside of stopgrads, though it can appear within stopgrads in multiple terms. ## 4 Stationary Points of Stopgrad Flow Map Objectives 

Flow maps learn to sample probability flow ordinary differential equations ( ODE s) in few steps, and are trained with objectives involving stopgrad operators. We now analyze the stationary points of these stopgrad flow map objectives. We begin by reviewing background. 

Stochastic Interpolants Given simple x0 ∼ q0 and data x1 ∼ q1, stochastic interpolants [26, 1] define a density path by constructing xt = αt x0 + σt x1, for t ∈ [0 , 1] . Under this construction, there exists a velocity field v(t, x ) := E[ ˙ xt | xt = x] with ˙xt = ˙ αtx0 + ˙ σtx1, such that the ODE 

dˆxt = v(t, ˆxt) dt has the same marginal densities as xt. The ODE connection provides a way to sample the marginals of xt while only having access to a sample of one endpoint and the velocity field v. In practice, v is learned by regressing a model vθ against ˙xt via the so-called flow-matching loss E[∥vθ (t, xt) − ˙xt∥2], and new samples are generated by discretizing the ODE .

## 5 Convergence of Functional Semi-Gradient Flow for Flow Map Objectives 

It is well known that standard gradient descent converges to stationary points under standard smooth-ness and step-size conditions [20]. Without stopgrads, the functional gradient g likewise defines a descent direction (when −g[f ] ∈ D ), and flowing along it brings optimization to a stationary point in function space. However, for stopgrad objectives which have semi-gradient update fields, it is not obvious whether following the semi-gradient field arrives at a stationary point or not. Thus, our preceding characterization of stationary points for stopgrad flow map objectives must be paired with an analysis of convergence. Here we show two things. First, semi-gradients are generally not gradients of any scalar objective; we confirm this concretely for MeanFlow, IMF , slim-LSD , and slim-ESD , so standard optimization theory does not guarantee their convergence. Second, despite this, functional semi-gradient flow does converge for MeanFlow, IMF , slim-LSD , and slim-ESD .

5.1 When is a semi-gradient the gradient of an objective? 

A natural question is, when is the semi-gradient g also the gradient of some scalar functional 

J : M → R—equivalently, whether g is a conservative vector field on M. Knowing that g is a gradient of some J would then mean that the updates still minimize some J that could be related to 

L. This question is well-studied in the context of TD learning [6, 30]. Here, we provide a general result for functionals following the stopgrad regression principle.

Corollary 6. The semi-gradients of LMF , LiMF , LLSD -slim , and LESD -slim are not gradients of any twice continuously differentiable scalar functional J : M → R in ⟨· , ·⟩ μ (in the sense of Theorem 2).

## 7 Related work 

Flow maps and consistency models. Flow maps and consistency models train networks to integrate probability-flow ODEs in few steps [41, 40, 28, 21, 37, 8, 36]. Many of these approaches use stopgrads to avoid backpropagating through model derivatives or nested model evaluations. We discuss the objectives of [9] and [15] in detail. Goldstein et al. [17] proved stationary-point results for SGFlow, a related stopgrad approach, but this approach still differentiates through forward-mode derivatives. In this work, we prove uniqueness of the true flow map as a stationary point for MeanFlow, improved MeanFlow, and our slim ESD /LSD variants, and additionally prove convergence of functional semi-gradient flow for these methods. 

Stopgrads and semi-gradients. Semi-gradients have been studied extensively in RL [42, 2, 43, 6], where TD-style updates are not gradients of any fixed loss but nonetheless converge under conditions related to the structure of the Bellman operator and its fixed points [30, 14, 11, 32]. Non-conservative update fields also arise in differentiable games such as GAN s [3, 24]. We derive our functional stopgrad formalism from first principles—perturbing only non-stopgrad occurrences of f —and verify that it reduces to PyTorch’s detach in finite dimensions. The same construction is used in the context of fine-tuning and sampling in the proofs of adjoint matching and adjoint sampling [13, 19]. Ponce et al. [33] studies two-player settings used in self-supervised methods such as BYOL ; there, stopgrads prevent model collapse for objectives whose minima would otherwise be collapsed solutions. 

## 8 Discussion 

We formalized the stopgrad operator in the calculus of variations, and proved a general theorem (Theorem 1) characterizing stationary points of stopgrad functionals. We analyzed stationary points and convergence for flow map objectives with stopgrad, and proposed slim stopgrad placements for  

> LSD

and ESD that avoid differentiating through derivatives of f , reducing training memory by 2×.Looking forward, physics-informed neural networks (PINN) losses regress against PDE residuals and share structural similarities with flow map objectives [18]. Our stopgrad regression principle may be used to propose stopgrad placements for PINN losses. 

Limitations. Our analysis is variational (infinite capacity, continuous optimization), so finite-width networks and stochastic gradient descent may behave differently. Our convergence results for IMF ,slim ESD and slim LSD assume perfect flow-matching pretraining. 12 Acknowledgments

In this section, we highlight the generality of the stopgrad regression principle by showing that it applies to stopgrad objectives not just for flow map training, but also for reinforcement learning and diffusion sampler training. ## K Experimental Methods 

K.1 CIFAR-10 Experiments Data. We use the CIFAR-10 dataset [23]. 

Architecture. We use the Song U-Net used in [15]. We use image resolution 32, in channels 3, out channels 3, model channels 18, num blocks 4, channel mult noise 2, resample filter [1,3,3,1], channel mult [2,2,2], encoder type standard, and decoder type standard. 

Compute. We ran each experiment (a given method) for 200k gradient steps. To accomplish this, for each experiment we used 8x A100 GPUs. Each method was able to reach 200k steps with 96 hours of training. 

Training Details. 

• Dataloading. We use pin-mem = True and 4 workers. • Time sampling. We use min times 1e-4 and max times 1 - 1e-4 for both training and sampling. We use probability t equals u set to 0.25. • EMA. We use EMA decay 0.9999. We start the EMA model at the 40k training steps model, and update once per gradient step thereafter. • Batch Size. We use batch size 64 per GPU and use 8 GPUs, meaning the effective batch size is 64*8=512. • Optimization. We use the AdamW optimizer with betas (0.9, 0.999). We use base learning rate 2e-4. We use linear warmup from 1e-6 up to the base learning rate for the first 20,000 steps. After warmup, the learning rate is constant at the base learning rate. • Seed. We use seed 0. • Velocity Warmup. We do not use any velocity warmup steps, similar to [15] and unlike [9]. • Dropout. We use dropout 0.20 • Adaptive Loss Weight. We use the adaptive loss reweighting from [15] with norm-p set to 0.75 and norm-eps set to 1e-3. 

Evaluation Details. We evaluate FID from the non-EMA and EMA models every 25,000 steps. We evaluate this FID for several different sampling step counts per checkpoint, with number of function evaluations in {1,10,50,100}. We compute FID with the standard 50,000 samples using batch size 128. To compute FID, we use torchmetrics.image.fid.FrechetInceptionDistance .36 K.2 ImageNet Experiments 

We use the B4 model from the meanflow-jax github repository which is a 90M diffusion transformer. We adopt their default settings, which uses patch size 4, learning rate of 0.0001, batch size 256, adam b2 of 0.95, and adaptive L2 weighting norm power of 1.0. We run flow-matching warmup for 10 epochs, and train for a total of 40 epochs. We use gradient surgery, prioritizing the diagonal gradient. Each run trained on 4x B200s, and training took about 8 hours.
