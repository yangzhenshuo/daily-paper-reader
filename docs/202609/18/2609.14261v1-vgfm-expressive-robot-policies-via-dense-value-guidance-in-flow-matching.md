## 摘要
近期的机器人学习范式日益依赖大规模机器人交互离线数据集来训练控制策略。富有表现力的生成模型能够实现丰富且多模态的动作表示，从而扩展了该范式在复杂机器人控制中的能力。然而，使用多步生成式动作器进行策略改进仍然具有挑战性。在离线强化学习（RL）中，将基于价值的目标融入生成轨迹通常会带来显著的训练复杂性，包括通过时间反向传播（BPTT）、辅助架构或蒸馏损失。我们提出价值引导流匹配（Value-Guided Flow Matching，VGFM），一种可扩展的离线 RL 框架，能够在基于流的策略中实现密集的价值引导塑形，同时避免 BPTT 和额外的算法开销。VGFM 将策略参数化为动作（x 预测）空间中的条件流匹配模型，确保每个中间流步骤都产生一个有效的机器人动作，并能由标准离线 RL 评价器直接评估。该设计允许在随机采样的流时间上施加价值引导，而无需对整个生成轨迹进行微分，同时通过改变底层流 ODE 的离散化来保持推理时的灵活性，且无需重新训练。在 OGBench 中的机器人运动与操作任务上进行评估，VGFM 在严格的评估协议下于广泛任务中取得了强劲性能。在极少超参数调优的情况下，这些结果表明，VGFM 为长时程、目标导向的机器人控制中的富有表现力策略学习提供了一种简单、可扩展且有效的方法。

## Abstract
Recent robot learning paradigms increasingly rely on large offline datasets of robotic interactions to train control policies. Expressive generative models enable rich and multimodal action representations, expanding the capability of this paradigm for complex robotic control. However, policy improvement with multi-step generative actors remains challenging. In offline reinforcement learning (RL), incorporating value-based objectives along generative trajectories often introduces substantial training complexity, including backpropagation through time (BPTT), auxiliary architectures, or distillation losses. We propose Value-Guided Flow Matching (VGFM), a scalable offline RL framework that enables dense value-guided shaping within a flow-based policy while avoiding BPTT and additional algorithmic overhead. VGFM parameterizes the policy as a conditional flow-matching model in action (x-prediction) space, ensuring that each intermediate flow step produces a valid robot action that can be directly evaluated by a standard offline RL critic. This design allows value guidance to be applied at randomly sampled flow times without differentiating through the entire generative trajectory, while preserving inference-time flexibility by varying the discretization of the underlying flow ODE without retraining. Evaluated on robotic locomotion and manipulation tasks in OGBench, VGFM achieves strong performance across a wide range of tasks under rigorous evaluation protocols. With minimal hyperparameter tuning, these results demonstrate that VGFM provides a simple, scalable, and effective approach for expressive policy learning in long-horizon, goal-oriented robotic control.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：机器人学习日益依赖大规模离线数据集训练控制策略。离线强化学习（Offline RL）可在不与环境交互的情况下优化策略，避免在线探索的安全风险与高成本。
- **核心矛盾**：
  - 离线 RL 的关键挑战是**分布偏移**——策略可能产生数据集外（OOD）动作，导致价值估计不可靠。
  - 真实机器人数据集常呈现强**多模态与组合结构**（不同抓取姿态、接近角度、路口左转/直行等），单峰高斯策略难以刻画。
  - 扩散/流匹配等生成式策略虽表达力强，但嵌入基于价值的策略改进时非常困难。
- **具体痛点**：在 DDPG+BC / TD3+BC 类 actor-critic 框架中，策略改进需对 Q 函数关于策略输出求梯度。当策略是多步 ODE 积分的流匹配模型时，这要求**通过时间反向传播（BPTT）**贯穿整条生成轨迹，带来：
  - 高计算与显存开销；
  - 随积分步数增加而加剧的数值不稳定（梯度消失/爆炸）；
  - 复合近似误差。
- **已有方案的取舍**：
  - FQL 通过蒸馏到单步网络避免 BPTT，但**牺牲推理时可扩展性**；
  - SORL 用 shortcut 模型支持推理权衡，但训练**仍需 BPTT**；
  - SSCP 避免 BPTT，但多步推理收益有限；
  - DQL/CAC 需对整条生成轨迹反传。
- **整体含义**：VGFM 试图在"表达力强（多步生成）"与"训练简单稳定（无 BPTT、无辅助损失）"之间取得兼顾，为长时程、目标导向的机器人控制提供可扩展方案。

## 2. 方法论

### 2.1 核心思想

- 从 KL 正则化策略改进目标出发，其最优解为优势加权形式，对动作求梯度得到**分数分解**：
  - ∇ₐ log π*(a|s) = ∇ₐ log π_β(a|s) + (1/α)∇ₐ Q(s,a)
  - 即策略改进 = **行为匹配项** + **价值引导项**。
- 该分解表明：价值梯度理论上可在生成轨迹的**每个中间点**提供引导（密集信用分配），而非仅在终末动作。
- VGFM 的关键洞察：若能让每个中间流步都直接输出**有效动作**，就可用标准、时间无关的 critic 直接评估它，从而在随机采样的流时刻施加价值监督，**无需对生成轨迹微分**。

### 2.2 关键技术细节

- **流匹配策略参数化**：
  - 以线性插值构造轨迹：a_t = (1−t)a₀ + t a₁，t ~ U[0,1]，a₀ ~ N(0,I) 为基分布样本，a₁ 为数据集动作。
  - 生成过程由 ODE 描述：da_t/dt = u_θ(s, a_t, t)，u_θ 为速度场。
  - 行为正则化由构造实现：流匹配损失 L_FM = E‖u_θ(s,a_t,t) − (a₁−a₀)‖²，其最优速度场把质量从 p₀ 精确输运到数据动作分布，**保守性内嵌于策略参数化**，而非事后加 KL 惩罚。

- **x-prediction 参数化（BPTT-free 的核心）**：
  - 网络直接预测终末动作 â_θ(s,a_t,t)，速度解析恢复：u_θ = (â_θ − a_t)/(1−t)。
  - **Lemma 1（动作空间有效性）**：在 x-prediction 下，任意状态、中间流状态与 t∈[0,1)，预测 â_θ 都位于动作空间 A 内，可被时间无关的 critic Q_φ(s,a) 直接评估。
  - 证明要点：â_θ 是动作空间的直接预测（而非速度/噪声向量），且流匹配目标在 t 上取期望，使预测始终被正则化到经验动作分布附近，从而保证 critic 梯度局部有意义。

- **密集价值监督**：
  - 对采样状态 s、数据集动作 a₁、基样本 a₀、随机时间 t，构造 a_t 并施加：
    - L_πQ(θ) = −E[ Q_φ(s, â_θ(s,a_t,t)) ]
  - 梯度只流经**采样时刻 t 的网络参数**，不穿越流动力学、不跨多个时间步，因此每次迭代提供独立监督信号，实现沿轨迹的密集 ∇ₐQ 引导。

- **组合目标**：
  - L(θ) = α·L_FM(θ) + L_πQ(θ)，α ≥ 0 平衡行为正则与价值引导。
  - L_FM 实现 ∇ₐ log π_β（行为匹配），L_πQ 实现 ∇ₐQ（价值引导）。
  - critic 用标准 Bellman 备份损失（clipped double Q-learning）同步优化。

### 2.3 算法流程（文字说明）

- **训练（Algorithm 1）**：采样数据批 → 更新 critic（式 16）→ 采样 a₀ ~ N(0,I)、a₁ ← a、t ~ U[0,1) → 构造 a_t → 前向得到 â_θ → 恢复速度 u_θ → 计算 L_FM 与 L_Q → 以 αL_FM + L_Q 更新 θ → Polyak 更新目标网络。
- **推理（Algorithm 2）**：从 x₀ ~ N(0,I) 出发，用 Euler 法对 ODE 积分 T 步（每步用 â_θ 恢复速度），返回 x₀。**T 可在测试时任意调整，无需重训**。

## 7. 优点

- **方法简洁**：无 BPTT、无辅助网络、无蒸馏或 shortcut 损失，是相对 DQL/FQL/SORL/SSCP 的显著工程优势。
- **理论抓手清晰**：从 KL 正则化最优解的分数分解出发，用 Lemma 1（动作空间有效性）把"密集价值引导"与"免 BPTT"两个目标自然衔接。
- **行为正则化内嵌**：流匹配本身将轨迹锚定到数据分布，比事后 KL 惩罚更优雅，也解释了中间预测为何可被 critic 可靠评估。
- **推理时算力可调**：同一模型可通过 T 在测试时权衡算力与性能，且实测 wall-clock 成本近似恒定，实用性强。
- **实验协议严格**：采用官方 OGBench 协议、8 seeds、6000 次 rollout/条目、最后三 checkpoint 平均，统计可信度高。
- **超参负担低**：相比多辅助损失方法需调多个权重，VGFM 仅需 α 一个系数。
