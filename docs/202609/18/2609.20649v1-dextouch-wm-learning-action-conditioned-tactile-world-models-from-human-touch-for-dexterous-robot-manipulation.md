## 摘要
学习接触丰富的灵巧操作的预测模型需要密集的触觉交互，但这类数据在真实机器人上难以规模化扩展，并且受限于特定具身形态的传感器。我们提出 DexTouch-WM，一种动作条件世界模型，它从可扩展的人类触觉中学习，以联合预测未来的 RGB 观测和双侧触觉动力学。我们的洞见是：当人类与机器人的触觉观测和动作空间变得兼容时，人类和机器人操作共享可迁移的接触动力学。我们在人类手和灵巧机器人手上部署具有共享传感布局的柔性压阻阵列，并将人类运动重定向到机器人动作空间，从而使人类交互能够监督用于真实机器人预测的同一动力学模型。DexTouch-WM 通过解剖感知的触觉 token 和对齐的动作条件，将预训练视频专家与轻量级触觉专家耦合起来。在人类到机器人的规模化实验中，我们保持五小时真实机器人监督固定不变，同时将人类交互从 0 小时增加到 100 小时，并观察到在留出的机器人域视觉、几何和接触预测方面取得显著提升，尽管人类和机器人任务集不相交。除预测之外，我们将世界模型评估为用于策略评估的代理环境，以及用于真实机器人策略学习的合成轨迹生成器，表明可扩展的人类交互为学习灵巧机器人世界模型提供了互补的数据轴。

## Abstract
Learning predictive models of contact-rich dexterous manipulation requires dense tactile interaction, but such data are costly to scale on real robots and remain tied to embodiment-specific sensors. We introduce DexTouch-WM, an action-conditioned world model that learns from scalable human touch to jointly predict future RGB observations and bilateral tactile dynamics. Our insight is that human and robot manipulation share transferable contact dynamics when their tactile observations and action spaces are made compatible. We deploy flexible piezoresistive arrays with a shared sensing layout on both human and dexterous robot hands, and retarget human motion into the robot action space so that human interaction can supervise the same dynamics model used for real-robot prediction. DexTouch-WM couples a pretrained video expert with a lightweight tactile expert using anatomy-aware tactile tokens and aligned action conditioning. In human-to-robot scaling experiments, we keep five hours of real-robot supervision fixed while increasing human interaction from 0 to 100 hours, and observe substantial improvements in held-out robot-domain visual, geometric, and contact prediction despite disjoint human and robot task sets. Beyond prediction, we evaluate the world models as surrogate environments for policy evaluation and as generators of synthetic trajectories for real-robot policy learning, showing that scalable human interaction provides a complementary data axis for learning dexterous robot world models.

## 1. 核心问题与研究动机

- **背景**：接触丰富的灵巧操作受制于无法从图像直接观测的物理交互状态（如接触压力、滑移、临界卡滞），视觉相似的运动会对应完全不同的接触状态；触觉对感知与控制此类交互至关重要。
- **现有局限**：
  - 动作条件世界模型（预测观测在候选动作下的演化）已用于策略评估、学习式仿真与合成数据生成，但**仅预测视频的模型无法表示决定操作结果的接触动力学**。
  - 近期视觉-触觉世界模型虽能联合预测视觉与触觉，但数据采集仍依赖**机器人遥操作**，导致数据集与特定本体、传感器配置强绑定，规模小且多局限于平行夹爪或孤立指尖传感器。
- **核心洞见**：当人类与机器人的**触觉观测**与**动作空间**被变得兼容时，二者共享可迁移的接触动力学，因此可通过可穿戴传感将触觉数据采集与机器人本体解耦。
- **整体含义**：提出 DexTouch-WM——从可扩展的人类触觉中学习、联合预测未来 RGB 观测与双侧触觉动力学的动作条件世界模型，将人类交互确立为学习灵巧机器人世界模型的**互补数据轴**。

## 2. 方法论

### 2.1 问题形式化

- 给定初始 RGB 观测 $v_0$、双侧触觉图 $x_0$、语言指令 $\ell$、未来位姿序列 $a_{1:T}$，学习联合分布：
  $$p_\theta(v_{1:T}, x_{1:T} \mid v_0, x_0, a_{1:T}, \ell)$$
- 人类与机器人共用 **67 维位姿表示**：双侧手腕运动（首帧相对）+ 双侧 20-DoF 手部构型 + 头部相机运动。

### 2.2 核心架构

- **双专家耦合**：以 Wan2.2-TI2V-5B 初始化的预训练视频专家（含冻结视频 VAE）+ 轻量级触觉专家，采用 **Mixture-of-Transformers** 结构，每层通过掩码联合自注意力交换上下文，同时保留模态专属的 AdaLN 与前馈通路。
- 首帧 RGB 经冻结 VAE 编码并作为时间索引 0 的干净潜变量保留，后续视频潜变量加噪预测；语言与初始触觉状态提供上下文。
- 冻结解码器重建未来 RGB 帧与压力图。

### 2.3 三项关键设计

- **解剖感知触觉 Tokenization（Split-Hands）**：
  - 每只手 320 个 taxel（5 个 4×4 指尖垫 + 1 个 15×16 手掌垫）。
  - 拒绝将触觉图视为单一稠密图像（会引入解剖上不连通区域间的伪邻接）；而是将双手对齐到统一解剖坐标系，指尖与手掌分别用**共享编码器**，配合 pad identity embedding 保留解剖对应关系。
  - Tokenizer 以接触加权重建预训练后冻结，避免大量非激活 taxel 主导表示。
- **锚定残差触觉潜变量**：
  - 令 $z_t = E_x(x_t)$，预测相对初始状态的变化 $r_t = z_t - z_0$，解码为 $\hat{x}_t = D_x(z_0 + \hat{r}_t)$。
  - 将预测聚焦于动作诱导的接触变化，同时保留初始压力背景。
- **双速率动作条件**：
  - 视频 VAE 因果压缩未来帧 4 倍，触觉保持观测速率，故各自在原生潜分辨率下条件化：$c^v_j = \phi_v(a_{4j-3:4j})$，$c^x_t = \phi_x(a_t)$，且 $c^v_0 = c^x_0 = 0$。
  - 通过 AdaLN 将位姿注入各专家的时间步调制；四帧位姿块条件化视频，帧级位姿保留触觉的细粒度时序线索。

### 2.4 训练目标

- 两专家均用条件流匹配训练：
  $$\mathcal{L} = \mathcal{L}^{FM}_{video} + \lambda_{tac}\mathcal{L}^{FM}_{tactile}$$
- 初始视觉潜变量不计入损失；触觉项预测残差并仅在接触/时变 token 上评估；联合注意力耦合模态而无需对齐损失。

### 2.5 数据采集与动作对齐

- **HumanTouch 采集**：Moxian 触觉手套（360 taxel/手 @60Hz，训练用 320）+ Manus MetaGloves 手指追踪 + HTC Vive 腕部 6-DoF + 双腕相机与头部相机；标定得到相机内外参与统一时间基准，输出 25 关键点 3D 手骨架。
- **人→机器人动作对齐**：经标定相机-世界对齐、手部几何归一化，用逆运动学重定向到 WujiHand2：
  $$(e^h_t, J^h_t) \xrightarrow{A} (e^r_t, q^r_t)$$
  最终动作表示 $a_t = [e^L_t, e^R_t, q^L_t, q^R_t, e^c_t] \in \mathbb{R}^{67}$，无需学习触觉域映射即可让人类轨迹监督机器人世界模型。

## 6. 主要结论与发现

- **架构结论**：
  - Split-Hands 相比 Grid 重建误差更低、Contact-IoU 收敛显著更快，说明保留解剖结构是建模稀疏局部接触的有效归纳偏置。
  - Cross-Attn 几乎不损害像素级保真（PSNR/SSIM/LPIPS 与 V-only 相当），但会降低语义与轨迹一致性（Trajectory Accuracy 从 ~0.88 降至 0.85）；AdaLN（Robot-only）缓解跨模态干扰，PSNR 从 22.1 升至 23.5、LPIPS 从 0.12 降至 0.10，触觉 Contact-IoU 从 0.39 升至 0.42、Contact-F1 从 0.52 升至 0.55。
- **规模化结论**：固定 5h 机器人数据、人类数据从 0 增至 100h，机器人域留出集上视觉 PSNR 23.47→27.10、Trajectory Accuracy 0.89→0.96、Geometry Error 0.13→0.10；触觉 PSNR$_{taxel}$ 24.81→29.18、Contact-IoU 0.42→0.59、Contact-F1 0.55→0.71。
  - **接触迁移强于视觉迁移**；视觉指标在 50–100h 间趋于饱和，而接触预测持续改善；+10h 人类数据在触觉指标上几乎无增益，主要收益出现在 50–100h。
- **策略评估器结论**：WM-Mix 平均 Pearson 相关性高于 WM-Robot（0.844 vs. 0.646），平均 MMRV 更低（0.017 vs. 0.025）；在 Place Shoes 上修正了 π0.5 与 X-VLA 的排序反转；但 Stand Bottle 两模型均出现排序反转，说明平均提升不意味着消除所有任务级排序错误。
- **数据生成器结论**：+WM-Mix 使 FTP-1 四任务均值从 0.731 降至 0.694，π0.5 从 0.625 降至 0.494，X-VLA 从 0.500 降至 0.400（Stand Bottle 为 0）；+WM-Robot 均值分别为 0.688、0.563、0.506。即**世界模型作为评估器的一致性并不能保证其合成数据具备同等的策略训练效用**，效用取决于策略与任务。

## 7. 优点

- **数据采集范式创新**：用可穿戴压阻手套将触觉数据采集与机器人本体解耦，并在人手与灵巧手上部署**共享传感布局**，从硬件层面消除触觉域映射需求，直击该领域最大瓶颈。
- **软硬件协同对齐**：共享触觉布局 + 相机-世界标定 + 逆运动学重定向到 67 维统一动作空间，使人类轨迹可直接监督机器人世界模型，无需学习跨域触觉映射。
- **表示设计有物理与解剖依据**：Split-Hands tokenization 避免伪空间邻接；残差潜变量锚定初始触觉以聚焦动作诱导变化；双速率条件匹配两种模态的原生时间分辨率。
- **实验协议严谨**：固定机器人监督、人机任务集不相交，使"人类数据带来跨任务迁移"的结论更具说服力；策略评估采用闭环 rollout、匹配初始帧、多评分者、Pearson + MMRV 双重度量。
- **下游任务验证完整**：同时验证世界模型作为策略评估器与合成数据生成器两种用途，并诚实报告了数据生成收益不一致的负面结果。

- **评测主观性风险**：真实世界与想象 rollout

评分由人类进行，虽以 5 名评分者取平均降低噪声，但**未报告评分者间一致性指标**（如 Krippendorff's α、ICC），也未说明评分者对模型身份的盲测设置；因此"真实 vs. 想象"的一致性或差异中，主观偏好成分难以完全剥离。

- **人机触觉硬件并非严格同构**：人类采集与机器人部署虽采用同款压阻手套与相同 taxel 布局，但人手与 WujiHand2 的指节长度、指尖曲率、接触面积与佩戴预紧力不同，可能造成同一接触事件的压力幅值与空间展宽分布存在系统性偏移；论文未量化这一"同布局、异几何"的残余域差，也未报告对齐后的接触响应一致性验证。
- **动作对齐误差未被评估**：67 维统一动作空间依赖相机-世界标定、手部几何归一化与逆运动学重定向，但论文未报告 IK 重定向的关节误差、自碰撞/不可达处理策略，以及这些误差如何传播到世界模型的动作条件上。若人类轨迹在重定向后存在系统偏差，跨域迁移的收益可能被高估。
- **未做语言条件的消融**：语言指令 $\ell$ 被纳入联合分布条件，但缺少"去语言"对照，因而无法判断视觉-触觉预测的增益究竟来自跨模态耦合还是来自指令提供的任务先验。
- **长时程误差累积未讨论**：世界模型以教师强制式的流匹配目标训练，评测中的 rollout 时域有限；缺少对自回归展开步数增加时视觉与触觉误差增长曲线（如漂移、模式坍缩、接触状态发散）的分析，而这恰是"世界模型作为评估器/数据生成器"最关键的可靠性边界。
- **本体与任务泛化边界未知**：全部机器人实验固定在 Tianji 机械臂 + 20-DoF WujiHand2 上，未验证换用其他手型、自由度或传感器后共享传感接口假设是否仍成立；任务集合限于桌面双手操作，未涉及移动、工具使用等更开放场景。

## 9. 总体评价与启示

- **贡献定位**：本文的核心贡献不在单一模型架构的突破，而在于**提出并验证了一条新的数据轴**——把触觉数据的可扩展性从"机器人遥操作"转移到"人类可穿戴采集"，并通过共享传感布局 + 统一动作空间使这条数据轴对机器人世界模型直接可用。这在触觉数据长期受制于硬件与本体绑定的领域，属于范式层面的推进。
- **方法论层面**：Split-Hands 解剖感知 tokenization、锚定残差触觉潜变量、双速率动作条件三项设计均有清晰的物理/解剖动机，而非纯经验调参；它们共同回答了一个具体问题——如何在极度稀疏且解剖结构化的接触信号上做生成式建模。
- **结论的稳健性**：最有力的证据是"固定 5h 机器人监督 + 人机任务集不相交"的规模化实验，接触指标随人类数据量持续提升且未饱和，说明迁移来自跨任务接触动力学而非任务级数据重叠。相对地，下游效用类结论（策略评估一致性、合成数据增益）证据强度较弱，且论文自身已诚实呈现了反例。
- **对后续研究的启示**：（1）触觉世界模型的瓶颈更可能在数据覆盖而非模型容量，扩展人类采集是性价比最高的方向；（2）"评估器一致性"与"训练数据可用性"应作为两个独立目标分别优化与验证；（3）接触相关指标的评估必须使用 Contact-MAE/IoU/F1 等接触区敏感度量，否则会被大面积非接触区域掩盖。
- **综合判断**：这是一篇问题选得准、软硬件协同扎实、实验协议较为克制且报告诚实的工作；主要短板集中在资源透明度、对齐误差量化、长时程可靠性与本体泛化验证上。若后续工作能补齐这些环节，人类触觉作为机器人世界模型互补数据轴的提法有望成为该领域的常规实践。
