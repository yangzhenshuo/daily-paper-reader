## 摘要
视觉运动策略同时观察任务场景和执行具身，使得具身特定的视觉线索能够影响动作预测。我们将这一现象作为视觉具身依赖（VED）进行研究，并通过对代表性策略进行线索冲突干预表明，可见的机器人构型可能成为任务进展的捷径。与其消除VED，我们认为应围绕支持控制与泛化的具身信息来结构化VED。我们通过在3D点云中进行具身规范化来实现这一点，用规范末端执行器表征（CER）替换原始具身，从而在抽象出具身特定形态的同时保留与控制相关的几何信息。其可编辑形式进一步支持针对不熟悉机器人构型的构型去相关增强。实验表明，具身规范化在无需机器人演示的情况下显著提升了人类到机器人的策略迁移，而如果不同时保留与控制相关的几何信息，仅仅移除具身是不足够的。我们进一步发现，当机器人构型与任务进展解耦时，CER本身也可能成为构型捷径；构型去相关增强缓解了这一失效模式，并在不牺牲已见构型性能的情况下恢复了稳健的恢复能力。总体而言，这些结果表明，稳健的视觉运动学习受益于对视觉具身信息进行结构化，而非将其移除。项目网站：https://tonyfang.net/ved

## Abstract
Visuomotor policies observe both the task scene and the acting embodiment, allowing embodiment-specific visual cues to influence action prediction. We study this phenomenon as visual embodiment dependence (VED) and show, through cue-conflict interventions across representative policies, that visible robot configuration can become a shortcut to task progress. Rather than eliminating VED, we argue that it should be structured around embodiment information that supports control and generalization. We realize this through embodiment canonicalization in 3D point clouds, replacing the original embodiment with a canonical end-effector representation (CER) that preserves control-relevant geometry while abstracting embodiment-specific morphology. Its editable form further enables configuration-decorrelation augmentation for unfamiliar robot configurations. Experiments show that embodiment canonicalization substantially improves human-to-robot policy transfer without robot demonstrations, while simply removing the embodiment is insufficient without preserving control-relevant geometry. We further find that CER itself can become a configuration shortcut when robot configuration becomes decoupled from task progress; configuration-decorrelation augmentation mitigates this failure mode and restores robust recovery without sacrificing performance on seen configurations. Together, these results show that robust visuomotor learning benefits from structuring, rather than removing, visual embodiment information. Project website: https://tonyfang.net/ved

# 论文结构化总结：Rethinking Visual Embodiment Dependence in Visuomotor Policies

## 1. 核心问题与整体含义

- **研究动机**：视觉运动策略（visuomotor policies）的观测中不仅包含任务场景，还不可避免地包含执行本体的外观、几何与构型信息，使本体特定的视觉线索直接影响动作预测。作者将这一现象定义为**视觉具身依赖（Visual Embodiment Dependence, VED）**。
- **背景问题**：现有跨具身研究主要关注不同具身之间的形态差异（morphology dependence），却较少探讨**同一具身内部**的构型依赖（configuration dependence）——即在成功演示中机器人构型常与任务进度强相关，导致策略把可见构型当作任务阶段的捷径，一旦二者解耦（如执行出错或恢复阶段）便产生错误动作。
- **核心主张**：VED 并非全然有害——末端执行器的视觉信息为操作提供了重要的空间与交互接地。问题在于策略依赖了**不可泛化的具身线索**。因此论文的目标不是消除 VED，而是**将其结构化**，使其围绕支持控制与泛化的具身信息展开。
- **理想属性**：有用的具身信息应同时具备三点——**控制接地（control-grounded）**、**跨具身共享（embodiment-shared）**、**可编辑（editable）**。

## 2. 方法论

### 2.1 核心思想
在 3D 点云空间中执行**具身规范化（embodiment canonicalization）**：移除原始具身几何，替换为**规范末端执行器表征（Canonical End-effector Representation, CER）**，在抽象掉具身特定形态的同时保留与控制相关的几何；再利用 CER 的**可编辑性**做**构型去相关增强**。

### 2.2 关键技术细节

- **具身规范化流程**：
  - 给定点云 $P_t$ 与具身掩码 $M_t$，先移除具身点得到任务场景点云 $P^{scene}_t = P_t \setminus P^{emb}_t$。
  - 定义规范末端模板 $C_0(s) = \{c_k\}_{k=1}^K$，为规范局部坐标系下的一组 3D 点。
  - 本工作针对夹爪操作，实例化为**线基规范夹爪**：两段远端线段表示夹爪两指（间距编码开口宽度），一段近端线段表示夹爪本体（提供几何朝向），线段离散为 $K$ 个点。
  - 给定夹爪位姿 $T_t \in SE(3)$，CER 为 $C(T_t, w) = T_t C_0(w_t)$。
  - 最终策略输入为 $\tilde{P}_t = P^{scene}_t \cup C(T_t, w_t)$。

- **人手到机器人的统一实例化**：对机器人演示直接从夹爪位姿与宽度获取 $T_t, w_t$；对人类演示，从手部关键点构建夹爪对齐坐标系——拇指-食指方向定义开口轴，其中点到手掌方向定义第二轴，据此确定 $T_t$ 与 $w_t$，实例化同一 CER。

- **构型去相关增强（Configuration-Decorrelation Augmentation）**：
  - 仅作用于**恢复可行状态**（recovery-eligible states，如自由空间接近、预抓取），排除接触约束状态。
  - 对时刻 $t$ 采样有界刚体扰动 $\Delta T_t$，构造 $\tilde{T}_t = \Delta T_t T_t$；增强观测为 $P^{aug}_t = P^{scene}_t \cup C(\tilde{T}_t, w_t)$。
  - 每个扰动构型配以**恢复轨迹**（平移线性插值、朝向用 SO(3) 球面插值 SLERP），到达 $T_t$ 后接回原演示轨迹：$\tilde{\tau} = [\tilde{T}_t \xrightarrow{interp} T_t, T_{t+1}, \dots]$。
  - 在线训练时以 $p_{aug} = 0.5$ 的概率施加，重复采样使策略暴露于多样化的“任务状态—构型”关联。

- **骨干网络**：由于操作定义在 3D 空间，采用 3D 视觉运动策略 **RISE** 作为骨干。

### 2.3 VED 诊断方法（线索冲突）
- 构造线索冲突观测 $o_{i \to j} = (E_j, S_i)$：保留阶段 $i$ 的任务状态 $S_i$，呈现阶段 $j$ 的具身构型 $E_j$。仿真中重渲染、真实世界中物理复现并重新采集 RGB-D。
- 定义**相对具身进度** $\Delta G = G_E - G_T$（分别向具身暗示动作与任务暗示动作的进度之差），并统计**具身跟随率（EFR）**：
  $$\text{EFR} = \frac{1}{N}\sum_{n=1}^{N}\mathbb{1}[\Delta G^{(n)} > 0]$$
- 动作距离 $d(a_1, a_2) = \|p_1 - p_2\|_2 + \lambda_R d_{SO(3)}(R_1, R_2)$，取 $\lambda_R = 0.06$ m/rad。

## 3. 实验设计

- **Ours（Mask + CER）**：完整具身规范化。

### 3.4 评估协议
- 每个任务随机采样 **25 个（或 20 个）初始物体构型**，所有策略在相同集合上评估一次。

- VED 诊断中对每个阶段对构造 **N = 20** 个线索冲突观测，所有策略评估同一集合。

## 6. 主要结论与发现

- **构型依赖确实存在且具有状态依赖性**：在 Pick Place Can 的 approach/transport 冲突中，BC-RNN 与 DP 强烈跟随具身线索；而在 grasp/pre-grasp 冲突中该倾向基本消失。Rotate Plate 上 ACT 与 RISE 也呈相似相位依赖模式——说明构型依赖并非单纯由策略性能弱导致，而是在可见构型强烈预测任务进度时变得显著。
- **具身规范化显著提升人类到机器人迁移**：平均成功率从 Vanilla 的 **20%** 提升至 **91%**；Mask Only 为 31%，CER Only 为 64%。
- **仅移除具身不足，需保留控制相关几何**：在 Open Drawer 上，Mask Only 将抓取从 44% 提升到 96%，但开启动作仅从 32% 到 36%；CER 则显著改善受约束的开启动作。Pour Balls 中 Mask Only 与 CER Only 常产生明显错位抓取。
- **CER 本身也可能成为构型捷径**：当机器人构型与任务进度解耦时，CER 在未见构型上表现脆弱（尤其 Pour Balls）。**构型去相关增强**能缓解该失效模式，在保持已见构型性能的同时显著提升未见构型下的恢复能力。
- **CER 可匹配完整机器人几何的 Oracle**：在 Collect Block 上 Oracle 与 CER 均为 96%，说明紧凑规范几何保留了完整形态中的控制相关信息。
- **训练时掩码改变表征依赖**：掩码将原始形态敏感度降低约 **32%**（配对差异 −0.00129，95% CI [−0.00178, −0.00082]），同时对 CER 的依赖仍然显著。
- **部署开销可控**：若可获得 URDF 与相机标定，直接渲染掩码仅增加 9 ms 延迟；移除部署时掩码仅使成功率从 96% 降至 92%。

## 7. 优点

- **视角新颖**：将“具身依赖”从“需要消除的噪声”重新定义为“需要被结构化的信息”，并提出控制接地、跨具身共享、可编辑三原则，具有概念层面的启发意义。
- **诊断方法严谨**：线索冲突观测设计在仿真与真实世界中均做到物理一致，配合 EFR 指标与两个控制变量（绝对动作预测、无本体感受输入），有效隔离了视觉构型依赖。
- **方法简洁且可操作**：CER 以轻量点云伪夹爪实现，可直接在 3D 空间中编辑，无需重渲染机器人或修改任务场景，便于与现有 3D 策略集成。
- **实验对照设计清晰**：通过 Vanilla / Mask Only / CER Only / Ours 的受控变体分离了“掩码”与“控制几何”两个因素；并用 Oracle 上界验证 CER 的信息保留程度。
- **兼顾实用工程考量**：评估了部署时掩码延迟与 URDF 渲染替代方案，提升了方法的落地可行性。
- **表征层面验证**：通过余弦距离敏感性分析，从机制上支持了“掩码抑制形态依赖但不消除 CER 依赖”的论断。

## 8. 不足与局限

- **末端执行器假设**：方法假设末端执行器捕获了主要的控制相关具身信息，对于非夹爪式或需要全身协调的任务可能不适用。
- **依赖可靠掩码**：性能依赖高质量具身掩码（SAM2 或 URDF 渲染），掩码失败或标定误差会影响规范化效果。
- **跨平台与任务覆盖有限**：仅在单一机器人平台（Flexiv Rizon 4 + AG-95 夹爪）和 4 个真实任务上验证；构型泛化仅 2 个任务，跨机器人平台与更多操作类型的泛化性尚未充分验证。
- **CER 仍可能成为新捷径**：作者已指出当构型与任务进度解耦时 CER 自身会形成捷径，去相关增强虽可缓解，但未从根本上消除该风险。
