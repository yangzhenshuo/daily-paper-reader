## 摘要
主流的机器人策略通常采用马尔可夫形式，但许多复杂的真实世界操作任务本质上是非马尔可夫的，需要超越当前观测的长时程记忆。现有记忆机制通常依赖语言摘要、不断增长的视觉窗口或二者组合，因此可能丢失细粒度视觉证据，或在历史覆盖范围与执行效率之间面临权衡。我们提出 MaP-WAM，一种记忆即计划（Memory-as-Plans）框架，它将依赖记忆的世界-动作建模分解为基于记忆的规划与以计划为条件的执行，并将长期多模态情景上下文用作规划时的证据，而不是反复让执行器以完整历史为条件。MaP-WAM 将记忆表示为包含语言指令和稀疏视觉上下文的已完成片段记录，并将这种情景记忆转换为紧凑计划，计划由下一片段级语言计划和相应的视觉引导组成。世界-动作-进度（WAP）模型在未知时长内执行每个计划，在推理时联合预测动作块和相应的执行进度，并通过计划-观测对齐校准预测进度，以实现自适应片段转换和闭环上下文更新。MaP-WAM 保持执行器上下文长度固定，而结构化注意力进一步在规划和执行中支持键值缓存。MaP-WAM 在 RMBench 上以 83.3% 的成功率取得最先进性能，并在真实机器人任务上达到 78.0% 的成功率，同时随着任务历史增长，执行器推理延迟保持大致恒定。

## Abstract
Mainstream robotic policies often adopt a Markovian formulation, but many complex real-world manipulation tasks are inherently non-Markovian, requiring long-horizon memory beyond the current observation. Existing memory mechanisms often rely on language summaries, growing visual windows, or their combinations, and may therefore lose fine-grained visual evidence or face a trade-off between history coverage and execution efficiency. We introduce MaP-WAM, a Memory-as-Plans framework that decomposes memory-dependent world-action modeling into memory-grounded planning and plan-conditioned execution, and uses long-term multimodal episodic context as planning-time evidence rather than repeatedly conditioning the executor on the full history. MaP-WAM represents memory as completed segment records containing language instructions and sparse visual context, and converts this episodic memory into compact plans comprising the next segment-level language plan and corresponding visual guidance. A World-Action-Progress (WAP) model executes each plan over an unknown duration by jointly predicting action chunks and corresponding execution progress at inference time, calibrating predicted progress through plan-observation alignment for adaptive segment transitions and closed-loop context updates. MaP-WAM keeps the executor context length fixed, while structured attention further enables key-value caching in both planning and execution. MaP-WAM achieves state-of-the-art performance on RMBench with an 83.3% success rate and attains 78.0% success on real-robot tasks, while maintaining approximately constant executor inference latency as task history grows.

## 1. 核心问题与整体含义

- **研究动机**：主流 VLA（视觉-语言-动作）模型与世界-动作模型（WAM）大多采用马尔可夫假设，仅以当前观测或固定短窗口历史作为条件。但许多真实世界操作任务本质上是**非马尔可夫**的——未来决策所需信息（如物体初始位置、之前执行到的语义阶段）在当前观测中已不可见。
- **现有记忆机制的不足**：
  - **语言记忆**（如 MemER、MEM）：将历史压缩为语言摘要，紧凑可解释，但会**丢失细粒度视觉/空间证据**（如 Swap T 任务中依赖精确视觉位置时性能骤降）。
  - **增长视觉窗口**（如 LingBot-VA 等因果 WAM）：保留更丰富的感知证据，但推理延迟与 GPU 显存随上下文增长而快速上升，形成**历史覆盖与执行效率的权衡**（约 1700 帧时 OOM）。
- **核心主张**：长时程视觉历史**不必在每个控制步都直接输入执行器**，它主要用于确定下一片段级计划与期望的视觉演化，执行阶段只需跟随一个记忆驱动的计划即可。
- **整体含义**：提出 **MaP-WAM**，将依赖记忆的世界-动作建模解耦为「记忆驱动的规划」与「计划条件的执行」，在保留长时程细粒度视觉记忆的同时，使执行器上下文长度固定、推理延迟近似恒定。

## 2. 方法论

### 2.1 核心思想
- 维护结构化的**多模态情景上下文** $C_{<k}$（全局指令 + 已完成片段的语言指令 + 稀疏视觉上下文），将其转换为紧凑的**记忆驱动计划** $C_k = \{l_k, G_k\}$（下一片段语言计划 + 视觉引导）。
- 规划阶段可访问长时程视觉证据；执行阶段仅以固定长度的计划前缀为条件，实现**固定上下文执行**。

### 2.2 关键技术细节

**(1) 结构化多模态情景上下文**
- 每个已完成片段 $i$ 记录为 $C_i = \{l_i, G_i\}$：语言指令 + 从该片段执行轨迹均匀采样的 $N=8$ 帧稀疏视觉上下文；初始观测记为 $G_0 = f_0$。

**(2) 记忆驱动的语言-视觉规划**
- **语言规划器** $\pi^l_P$：以全局指令 $l$、已完成片段指令 $l_{<k}$ 与紧凑关键帧集 $f^\star$（初始帧 + 每段末帧）为输入，用微调的 Qwen3.5-4B 预测下一子目标语言计划 $l_k$。
- **视觉规划器** $\pi^v_P$：基于 WAN-2.2-5B 初始化的**因果世界模型（CWM）**，以 $G_{<k}$、$l_k$、$l$ 为条件，用 flow-matching 目标生成视觉计划 $G_k$。
- **因果注意力**：采用块因果掩码，已完成证据成为可缓存的静态前缀，避免跨片段未来泄漏。

**(3) 世界-动作-进度（WAP）模型**
- 基于 **Mixture-of-Transformers（MoT）** 架构扩展预训练视频 DiT，加入动作专家（1.02B 参数，$d_a=1024$）与进度专家（207M 参数，$d_p=256$）。
- 联合预测三路目标：未来视觉动态 $y_v$、动作块 $y_a$、进度序列 $y_p$，训练目标为条件 flow-matching：
  - $L^m_E = L_{FM}(y_m, c)$，$m \in \{v, a, p\}$
  - 总损失 $L_E = \lambda_v L^v_E + \lambda_a L^a_E + \lambda_p L^p_E$
  - 共享条件 $c = (G_k, l_k, f_t, s_t, p_t)$
- **进度作为一等模态**：进度条件 $p_t$ 提供显式时间锚点，区分视觉相似但语义阶段不同的状态。
- 未来视觉分支在推理时可省略（仅作辅助世界建模目标），并遵循 FastWAM 的注意力隔离设计。

**(4) 闭环规划与执行**
- **计划-观测对齐校准**：部署时真实进度不可得，递归预测会累积误差。利用视觉计划按进度索引的特性，检索邻近计划帧与当前观测做 RGB 平均绝对像素差匹配，将进度条件向最相似帧的进度值更新。
- **进度门控片段转换**：对最近动作的预测进度取平均，超过阈值 $\tau=0.95$ 时结束当前计划，将真实执行观测重采样为稀疏视觉证据 $G_k$ 追加到情景上下文，触发下一轮规划（保持上下文基于真实观测而非生成预测）。

### 2.3 推理算法流程（Algorithm 1 简述）
初始化 $G_0 \leftarrow f_0$、$k \leftarrow 1$、$t \leftarrow 0$ → 循环：提取关键帧生成语言计划 $\hat{l}_k$ → 生成视觉计划 $\hat{G}_k$ → 预填充并缓存 WAP 计划前缀 → 段内循环：校准进度 $p_t$ → 联合生成动作与进度序列 → 执行动作收集观测 → 计算完成分数 $s$ → 若 $s \geq \tau$ 则重采样为 $G_k$ 并更新上下文、$k \leftarrow k+1$。

## 6. 主要结论与发现

- **性能 SOTA**：RMBench 总体成功率 **83.3%**，超越所有代表性基线（LingBot-VA 77.1%、Mem-0 42.0%、π0.5 10.4% 等）；Swap T 与 Press Button 均达 96%；Observe and Pick Up 从最强基线的 9% 提升至 19%。
- **真机表现**：Find Button 88%、Press Buttons 68%，而基线在 Press Buttons 上几乎失败。
- **效率优势**：执行器每动作块延迟在历史增长下保持约 **827 ms** 近似恒定；Full Context 变体在 1500 帧时延迟约为零历史延迟的 4 倍，1700 帧时显存超 80 GB 导致 OOM。
- **机制验证**：
  - 视觉计划必须接地于长时程情景证据，用当前观测条件的标准世界模型会生成错误物体/颜色/位置。
  - 进度条件对 Press Button（视觉相似的按下/释放阶段）尤为关键；进度校准对长时程 Blocks Ranking Try（平均 423.10 步）最能缓解递归漂移。

## 7. 优点

- **问题洞察深刻**：明确指出“长时程视觉历史不必每步输入执行器”，通过规划-执行解耦优雅地打破历史覆盖与效率的权衡。
- **记忆表示创新**：以“计划”作为记忆载体，兼顾任务语义（语言计划）与细粒度视觉证据（稀疏视觉计划），避免语言摘要的信息丢失与增长窗口的开销膨胀。
- **进度作为一等模态**：将进度从后验验证器/奖励信号提升为与动作、视觉动态联合生成并反馈的显式时间坐标，实现变时长执行与自适应段转换。
- **工程高效性**：结构化注意力掩码使规划与执行均可 KV 缓存，执行器上下文长度固定，延迟近似恒定，具备实际部署价值。
- **实验较完整**：仿真 + 真机 + 多组消融 + 效率分析，验证了各设计组件的独立贡献。

## 8. 不足与局限

- **依赖片段结构**：MaP-WAM 建立在现有基准提供的段级标注之上来组织记忆与进度；扩展到**未分段演示**需要自动片段发现，作者将其列为未来工作。
- **对齐度量较简陋**：计划-观测对齐采用**免训练的 RGB 平均绝对像素差**匹配，在视觉复杂场景下鲁棒性可能不足，学习式相似度度量或有提升空间。
- **真机实验规模有限**：仅 2 个任务、每任务 50 次试验，任务类型相对单一（按钮类），泛化性证据尚不充分。
- **训练设置不一致风险**：规划器多任务训练而 WAP 单任务训练，可能对基线与本方法的可比性造成一定影响。
- **计算资源未充分披露**：未给出总训练时长或 GPU 小时数，复现成本难以准确评估。
- **长时程误差累积**：进度递归预测仍存在漂移风险，虽经计划-观测对齐缓解，但在超长任务中的稳定性仍待进一步验证。
