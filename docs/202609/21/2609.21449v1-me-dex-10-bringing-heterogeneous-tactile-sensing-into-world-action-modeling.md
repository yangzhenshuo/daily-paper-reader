## 摘要
世界动作模型将视频模型的预测能力引入机器人动作生成，为建模未来视觉状态提供了丰富基础。触觉感知通过对物理交互的直接测量补充了这一基础。一些现有方法将触觉特征用作条件输入，但没有联合预测未来触觉状态、视觉观测和动作。我们的关键洞察是：触觉信号与视频一样，提供了对不断演化的世界状态的观测，因此应当与视频一起被建模为未来观测。我们提出 ME-Dex-1.0（MachEmbodied-Dex-1.0），一个用于视觉、触觉与动作联合学习的统一世界动作触觉模型。ME-Dex-1.0 采用 Mixture-of-Transformers 架构，包含视频专家、触觉专家和动作专家，并全部使用流匹配训练。我们使用共享注意力在中间层连接各专家，使动作生成在联合去噪过程中能够利用学习到的视觉与触觉动态表示。为支持多源异构触觉输入，规范手模型和统一触觉自编码器将来自不同本体和传感布局的触觉观测映射到共享的空间与潜空间。为应对配对的视觉、触觉和动作数据有限的问题，我们开发了 Agentic Tactile Data Engine，一个基于智能体的数据生产平台。它在仿真中的轨迹回放期间，用直接从力传感器记录的触觉数据补充 RoboTwin 和 DexJoCo。在 RoboTwin、DexJoCo 和 ManiFeel 仿真平台上的实验，以及真实机器人评估，表明使用配备触觉感知的夹爪和灵巧手时，操作性能得到提升。

## Abstract
World Action Models bring the predictive capabilities of video models into robot action generation, providing a rich foundation for modeling future visual states. Tactile sensing complements this foundation with direct measurements of physical interaction. Some existing methods use tactile features as conditioning inputs without jointly predicting future tactile states, visual observations, and actions. Our key insight is that tactile signals, like video, provide observations of the evolving world state and should be modeled as future observations alongside video. We present ME-Dex-1.0 (MachEmbodied-Dex-1.0), a unified World Action Tactile Model for joint visual, tactile, and action learning. ME-Dex-1.0 adopts a Mixture-of-Transformers architecture comprising a Video Expert, a Tactile Expert, and an Action Expert, all trained with flow matching. We use shared attention connects the experts in intermediate layers, allowing action generation to draw on learned representations of visual and tactile dynamics during joint denoising. To support multi-source heterogeneous tactile inputs, a Canonical Hand Model and a Unified Tactile Autoencoder map tactile observations from different embodiments and sensing layouts into shared spatial and latent spaces. To address the limited availability of paired visual, tactile, and action data, we develop the Agentic Tactile Data Engine, an agent-based data production platform. It supplements RoboTwin and DexJoCo with tactile data recorded directly from force sensors during trajectory replay in simulation. Experiments on the RoboTwin, DexJoCo, and ManiFeel simulation platforms, together with real robot evaluations, demonstrate improved manipulation performance using both grippers and dexterous hands equipped with tactile sensing.

## 1. 核心问题与整体含义

- **背景**：具身智能中机器人操作沿两条主线发展——视觉-语言-动作模型（VLA）直接由视觉与语言生成动作；世界动作模型（WAM）联合学习动作与未来视觉状态，把视频生成模型的动态预测能力引入控制。
- **缺口**：视觉描述"物体如何运动"，但物理交互还取决于"机器人如何施力、物体如何响应"。触觉能直接测量这一交互，然而现有工作多把触觉作为**条件输入**（conditioning），并不联合预测未来触觉状态、视觉观测与动作；已有预测性触觉工作（如 VT-WAM）尚未扩展到多源异构触觉。
- **关键洞察**：触觉信号与视频一样，是对演化中世界状态的**观测**，因此应与视频并列，被建模为**未来观测**而非单纯条件。
- **三大待解鸿沟**：
  - **数据 Gap**：RoboTwin、DexJoCo 缺乏原生触觉测量，HATO、ManiFeel 等触觉数据规模有限且格式不一，同步采集触觉与动作成本高。
  - **表示 Gap**：不同传感器与本体（夹爪、灵巧手）的触觉输入异构，缺乏共享表示难以联合训练。
  - **模型 Gap**：如何在预测架构中联合学习未来视觉、触觉与动作，并让未来触觉表示可被动作生成直接利用。
- **整体含义**：论文提出 ME-Dex-1.0，试图把触觉从"辅助条件"提升为"世界状态的一等观测"，为触觉增强的机器人操作提供跨本体、可扩展的统一框架。

## 2. 方法论

### 2.1 问题形式化

- 时刻 $t$ 输入：任务指令 $\ell$、首帧视觉观测 $I_t$、本体状态 $s_t$、当前触觉观测 $T_t$；经视觉/触觉编码器得到潜变量 $z^{vis}_t, z^{tac}_t$，共同构成条件 $C_t$。
- 目标：联合建模未来动作块 $A^+$、未来视频 $V^+$ 与未来触觉序列 $T^+$ 的联合分布 $p_\theta(A^+, Z^{vis,+}, Z^{tac,+}\mid C_t)$。
- **动作策略是该联合分布对动作的边缘化**：推理时联合采样动作与未来观测潜变量，仅保留动作输出。未来视频/触觉的真值仅用于训练，推理时不可得。

### 2.2 三专家混合 Transformer（MoT）

- 架构由 **Video Expert、Tactile Expert、Action Expert** 三个独立 Transformer 组成，全部以**条件流匹配**训练：
  - Video Expert 沿用 Wan2.2-5B：30 层、隐藏宽度 3072；
  - Action Expert：30 层、宽度 1024；
  - Tactile Expert：30 层、宽度 512，随机初始化（前两者由 Motus 预训练权重初始化）。
- 输入设置：Video Expert 接收编码首帧 + 加噪未来视频潜变量；Action Expert 接收本体状态 + 加噪真值动作；Tactile Expert 接收编码当前触觉帧 + 加噪未来触觉潜变量。
- 触觉被当作**时序观测模态**处理：未来触觉序列含 $T$ 帧，逐帧经冻结触觉编码器得到 $T\times N\times d$ 的潜变量序列，由 DiT 在潜空间去噪，推理时以同形状高斯噪声初始化。

### 2.3 H-Bridge 共享注意力

- 跨模态交互**仅限制在中间若干层** $B$（H-Bridge 层），其余浅层与深层各专家独立处理。
- 在桥接层内，各专家将特征投影到兼容注意力维度，对视频、触觉、动作 token 做联合注意力，再映射回各自隐藏宽度。
- 作用：把信息交换集中在网络中段，保留输入/输出端的模态专有处理，减少需要跨模态注意力的层数；使动作生成能在联合去噪过程中直接访问未来视觉演化与接触动态的中间表示。

### 2.4 联合训练与推理

- 各模态独立采样噪声水平 $\sigma_m\in[0,1]$ 与标准高斯噪声，构造加噪目标 $x^m_{\sigma_m}=(1-\sigma_m)x^m_0+\sigma_m\epsilon_m$ 与目标速度 $u^m=\epsilon_m-x^m_0$。
- 视频与动作使用均方误差，触觉使用**强调真值触觉潜变量变化**的加权平方误差。
- 总损失为三项流匹配损失的加权和 $\mathcal{L}_{joint}=\lambda_{vis}\mathcal{L}^{vis}_{FM}+\lambda_{tac}\mathcal{L}^{tac}_{FM}+\lambda_{act}\mathcal{L}^{act}_{FM}$。
- 推理：未来视频潜变量、未来触觉潜变量、动作均从高斯噪声初始化，在固定条件 $C_t$ 下由噪声水平 1 联合更新至 0，H-Bridge 在更新中交换信息；动作块为控制输出，冻结的视觉/触觉解码器可恢复预测观测。

### 2.5 统一触觉表示

- **触觉输入**：每个传感面 $r$ 提供力场 $F^{(r)}_t\in\mathbb{R}^{3\times H\times W}$（法向 + 两切向分量），布局掩码标识有效传感位置；预处理含平滑死区、逐通道 asinh 压缩、归一化与裁剪，法向/切向分别落在 $[0,1]$ 与 $[-1,1]$。
- **Canonical Hand Model（规范手模型）**：受人手启发，为左右手定义对应的手指与手掌区域，把灵巧手与夹爪视为该模板的形态变体；灵巧手各传感面映射到对应手指/手掌区域，RoboTwin 夹爪两个传感面映射到拇指与食指区域，每个面再划分为四个不重叠、有序的 patch。**区域掩码区分"未观测区域"与"观测到但无接触"**。
- **Unified Tactile Autoencoder（统一触觉自编码器）**：
  - 编码器跨传感面共享参数、逐帧独立处理：残差卷积提取局部力特征 → 面内窗口/移位窗口注意力 → 掩码学习池化（夹爪按四个 patch 分别池化，灵巧手整面池化）→ token 按规范槽位分配并加入区域与池化类型嵌入 → 两层掩码 Transformer 交换帧内有效区域信息，输出 $N$ 个区域 token；未观测区域保持掩码且输出为零。
  - 解码器以局部网格位置为 query 做交叉注意力，经残差 MLP 与卷积细化，由力头预测法向/切向分量、接触头预测接触概率；重建力场 = 力预测 × 接触概率 × 有效位置掩码。
  - 损失 $\mathcal{L}_{AE}=\mathcal{L}_{force}+\mathcal{L}_{contact}+\mathcal{L}_{change}+\lambda_{lat}\mathcal{L}_{latent}$：力损失在接触位置用 Smooth L1 并做接触门控、背景位置监督门控后重建；接触损失为平衡 BCE（软标签来自死区前的力幅值）；变化损失匹配相邻帧力差并加重接触发生/释放；潜损失约束"观测但无接触"区域池化特征趋近零输入下的结果。
  - 预训练后**冻结**，为联合模型提供触觉条件、未来触觉目标，以及预测潜变量的解码器。

### 2.6 Agentic Tactile Data Engine

- 基于智能体的数据生产平台，在仿真中**回放已有 RoboTwin / DexJoCo 动作**，让仿真力传感器直接记录触觉信号；同时生成并执行新轨迹以扩充触觉数据。
- 产出轨迹在同一时间窗内配对触觉信号、视觉观测与动作，同时提供当前观测条件与对齐的未来目标。

## 3. 实验设计

### 3.1 数据集与平台

- **RoboTwin**：用仿真力传感器补充触觉信号；混合 Clean + Random 共 **50 个任务、27,500 条轨迹**训练并在两种配置下评估；另设**仅 2,500 条 Clean 轨迹**训练以考察向 Random 配置的泛化。
- **DexJoCo**：补充触觉信号，按官方多任务设定在 **6 个单臂 + 5 个双臂共 11 个任务、1,100 条演示**上联合训练，评测配置为 rand-obj。
- **ManiFeel**：使用其三维触觉力观测，**4 个插入任务、每任务 50 条演示**，每任务单独训练与评估一个策略。
- **真机平台**：单臂 LeRobot SO-101（夹爪集成 Paxini PX6AX 触觉传感器）；双臂机器人（XR5-10-FS 机械臂 + Xynova Flex2 灵巧手）。

### 3.2 对比方法与评价指标

- RoboTwin：对比 $\pi_{0.5}$、Fast-WAM、Motus；并构造 $\pi_{0.5}$+Tac、Fast-WAM+Tac 等触觉条件变体（触觉 token 由预训练统一触觉自编码器编码）。
- DexJoCo：对比 DP-T、$\pi_{0.5}$、$\pi_{0.5}$+Tac、DECO、DECO.p（DECO 的触觉适配器变体）。
- ManiFeel：对比官方策略（记为 ManiFeel）。
- 主要指标为**闭环任务成功率**，成功判定采用各 benchmark 官方标准。

### 3.3 消融设置

- RoboTwin 上逐步消融：ME-Dex-1.0 (VA，仅视频+动作) → (Tac Cond.，加当前触觉条件) → (Full Joint，加未来触觉预测) → 完整模型（加 H-Bridge 共享注意力）→ (Zero Tac Input，评估时触觉置零)。
- 统一触觉表示评估：在三个平台数据上联合训练共享自编码器
