## 摘要
晶体结构预测（CSP）是计算材料发现的基础。包括 CDVAE、DiffCSP、FlowMM 和 CrystalFlow 在内的生成模型直接学习稳定晶体分布，但扩散和流匹配推理对每个候选需要数十到数千次顺序网络评估。我们提出 uFlowCSP，一种基于 MeanFlow 的 CSP 模型，它学习平均概率流速度，而非瞬时概率流速度。它可在 1 到 5 次评估中生成完整结构，实现 5 到 58 倍的推理加速，并具有相当或更优的性能。一个化学与对称性感知的 Transformer 使用规范原子排序、全局组成以及逐 token 化学嵌入。一个粗粒度晶系 token 仅在训练期间使用；它带来额外增益，尤其是在空间群一致性方面有所改善，尽管在推理时并不存在，推理仍仅依赖化学式。在 MP-20 上，每个目标生成 20 个候选时，单步与 CrystalFlow 相当（78.38% 对 78.34%），评估次数少 100 倍，实际耗时约低 10 倍。五步达到 83.64%，超过 CrystalFlow（在 2,000 次评估下为 78.34%）和 DiffCSP（在约 20,000 次评估下为 77.93%），同时评估次数少 20 倍。uFlowCSP 在 0.39–1.31 分钟内生成 10,000 个结构，而 CrystalFlow 需 6.5 分钟，DiffCSP 需 76.1 分钟。在 CSPBench 的能量排序前五结构及空间群准则下，五步 uFlowCSP 达到 72%/72%/65% 的结构、空间群和共识匹配率。CrystalFlow 在 100 步时达到 78%/73%/68%，但在五步时降至 49%/32%/31%。因此，uFlowCSP 提升的是每次网络评估的准确率，而不仅仅是峰值准确率。

## Abstract
Crystal structure prediction (CSP) is fundamental to computational materials discovery. Generative models including CDVAE, DiffCSP, FlowMM, and CrystalFlow learn stable-crystal distributions directly, but diffusion and flow-matching inference requires tens to thousands of sequential network evaluations per candidate.   We introduce uFlowCSP, a MeanFlow-based CSP model that learns the average, rather than instantaneous, probability-flow velocity. It generates a complete structure in one to five evaluations, delivering 5x-58x faster inference with equal or better performance. A chemistry- and symmetry-aware Transformer uses canonical atom ordering, global composition, and per-token chemistry embeddings. A coarse crystal-system token is used only during training; it provides additive gains, particularly improving space-group agreement despite being absent at inference, which remains formula-only.   On MP-20 with 20 candidates per target, one step matches CrystalFlow (78.38% vs. 78.34%) with 100x fewer evaluations and about 10x lower wall-clock time. Five steps reach 83.64%, exceeding CrystalFlow (78.34% at 2,000 evaluations) and DiffCSP (77.93% at about 20,000), while using 20x fewer evaluations. uFlowCSP generates 10,000 structures in 0.39-1.31 minutes, versus 6.5 for CrystalFlow and 76.1 for DiffCSP. Under CSPBench's energy-ranked top-five structure-and-space-group criterion, five-step uFlowCSP reaches 72%/72%/65% structure, space-group, and consensus match rates. CrystalFlow reaches 78%/73%/68% at 100 steps but falls to 49%/32%/31% at five. Thus, uFlowCSP improves accuracy per network evaluation, not merely peak accuracy.

## 1. 论文的核心问题与整体含义

- **研究背景**：晶体结构预测（CSP）是计算材料发现的基础任务——仅凭化学组成确定原子在周期性固体中的排列方式。传统方法将其视为势能面上的全局优化问题（如从头算随机搜索、USPEX 进化算法、CALYPSO 粒子群优化），但反复的 DFT 弛豫使其计算代价随原子数、晶胞大小和化学搜索空间急剧增长。
- **范式转变**：深度生成模型（CDVAE、DiffCSP、DiffCSP++、CrystalFormer、SymmCD、WyckoffDiff、MatterGen、CrystaLLM、FlowMM、CrystalFlow）将 CSP 重构为从材料数据库学习稳定晶体分布，训练一次即可直接生成结构。
- **核心痛点**：**推理仍是瓶颈**。扩散模型需数百至数千步去噪，流匹配模型需对速度场做多次数值积分，自回归模型逐 token 生成——三者都是串行过程。即便引入更强的对称性先验或条件化，也只是提升质量而非消除每候选的推理成本。
- **论文含义**：作者提出 **uFlowCSP**，将单步/少步生成建模引入 CSP，把瓶颈从"峰值精度"转向"每次网络评估的精度"，目标是让高质量晶体结构能在 1–5 次网络评估内生成，从而支持大规模材料筛选。

## 2. 论文提出的方法论

### 核心思想
- 基于 **MeanFlow**（Geng et al., 2025），学习概率流轨迹的**区间平均速度**而非**瞬时速度**，从而无需蒸馏或预训练即可实现单步生成。
- 任意两个时刻可通过一次跳跃关联：`z_r = z_t − (t − r) · u(z_t, r, t)`，其中 `u = 1/(t−r) ∫_r^t v dτ`。

### 关键技术细节

**晶体表示**
- 每个原子作为一个 token，状态 `x_i = [r_i ; vec(L)] ∈ R^12`：3 维笛卡尔坐标 + 9 维展平晶格矩阵（行优先）。
- 所有原子共享同一份晶格副本（冗余设计让 Transformer 通过自注意力在每个位置读取晶胞），采样后对晶格通道取平均还原为单一晶胞。
- 原子序数 `{z_i}` 由组成条件固定，流只传输连续坐标与晶格。

**MeanFlow 训练**
- 线性路径 `z_t = (1−t)x_1 + t·ε`，t=1 为纯噪声，t=0 为纯数据，瞬时速度 `v = ε − x_1`。
- 网络 `u_θ` 回归 stop-gradient 目标 `u_tgt = v − (t−r) d/dt u_θ`，总导数通过**前向模式自动微分**在同一前向传播中计算雅可比–向量积。
- 平方、自适应加权损失。

**采样**
- 从 `z(0) ~ N(0, I)` 出发，按均匀时间步 `t_0=1 > … > t_S=0`（∆t = 1/S）迭代：`z(k+1) = z(k) − ∆t · u_θ(z(k), t_{k+1}, t_k)`。
- S=1 为单步生成，S=5 为主配置。

**化学与对称性感知 Transformer**
- 12 层、隐藏维 768、12 注意力头；原子类型用 32 维可学习嵌入。
- **规范原子排序**：按 Pauling 电负性排序；训练时进一步按空间群轨道分组、按 Wyckoff 字母排序（用 pymatgen + spglib 预处理）。推理时仅按电负性排序，无需空间群标签。
- **逐原子化学特征**：在 token 上拼接 4 个固定描述符（电负性、原子半径、周期、族），输入 token `h_i = [a_i ; f_i ; r_i ; vec(L)]`。
- **全化学式特征**：元素分数向量经 MLP 得到 `e_formula`，全局应用。
- **粗粒度对称提示**：将空间群映射为 7 个晶系 + 1 个 null 类，得到 `e_sys`。
- 全局条件向量 `c = e_t + e_r + e_formula + e_sys`，通过**自适应层归一化（adaLN）**调制每个 Transformer 块。
- **训练辅助 token**：晶系 token 按 classifier-free guidance 以一定概率置为 null 类，使网络同时学习有/无对称条件的速度场；**推理时恒为 null**，因此生成仅依赖化学式，其收益本质是**正则化效应**。

**实现与训练**
- 数据：MP-20（≤20 原子/晶胞），标准 CDVAE 划分；180 个 CSPBench 评估结构从训练集移除。
- 700 epoch，bf16 混合精度，AdamW，恒定学习率 1e-4，batch size 256。
- MeanFlow 流比率 0.25，CFG dropout 概率 0.8，guidance scale 1.5。
- 两个协议各训练一个独立模型。

## 6. 论文的主要结论与发现

- **MP-20（协议 B）**：k=20 时，S=1 即以 78.38% 匹配 CrystalFlow 的 78.34%（NFE 少 100 倍）；S=5 达 **83.64%**，超过 CrystalFlow（78.34%，2,000 NFE）和 DiffCSP（77.93%，约 20,000 NFE），NFE 少 20–200 倍。S=5 的 RMSE 0.0619，与 FlowMM（0.0566）和 CrystalFlow（0.0577）相当，但 DiffCSP 仍更低（0.0492）。
- **速度**：生成 10k 结构耗时 **0.39 分钟（S=1）/ 1.31 分钟（S=5）**，对比 CrystalFlow 6.5 分钟、DiffCSP 76.1 分钟。
- **预算使用方式**：给定 100 次评估，uFlowCSP 生成多个快速候选达 83.64%，而 CrystalFlow 把相同预算用于精细积分单个候选仅得 62.02%。
- **CSPBench（协议 A）**：S=5 时达 **72 / 72 / 65%**（结构/空间群/共识）；CrystalFlow 在 S=5 时崩溃至 49/32/31%，只有在 S=100 时才达 78/73/68%（空间群仅比 uFlowCSP 高 1 个百分点，但 NFE 多 20 倍）。
- **消融结论**：四个条件信号**加性贡献**，并分为两组——
  - **规范原子排序**贡献最大跳跃（空间群 +14、共识 +12），且纯属预处理选择，说明"对称性问题大部分是 token 顺序问题，而非模型容量问题"；
  - **化学式嵌入**带来最大结构匹配增益（+8），逐原子特征进一步小幅提升几何；
  - **晶系辅助 token**最后贡献空间群 +5，属训练正则化效应（推理时置空）。
- **骨干对比**：Transformer 优于等变 GNN（72/72/65 vs 70/64/60），在对称性上差距更明显。
- **弛豫诊断（SiO₂, ORB-v3 代理）**：S=1 中位能量下降 2.41 eV/atom，S=5 降至 0.34 eV/atom，与 CrystalFlow S=100（0.51 eV/atom）相当；S=1 收敛率 86%、S=5 为 96%、CrystalFlow S=100 为 98%；弛豫后三者收敛到同一低能峰，说明差异在于原始输出距弛豫盆地的远近。
- **总体结论**：uFlowCSP 提升的是**每次网络评估的准确率**而非峰值准确率；平均速度表述在低步数下保持对称性，而普通流匹配会显著退化。

## 7. 优点

- **方法创新性**：首次将 MeanFlow 的单步/少步生成能力引入晶体结构预测，无需蒸馏或预训练，直接从平均速度场获得少步采样能力。
- **设计巧妙的对称性处理**：用"仅训练时使用的粗晶系 token"作为正则
