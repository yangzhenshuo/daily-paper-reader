## 摘要
视觉运动模仿策略在分布内视觉条件下可以表现出高性能，但在引入视觉相似的物体或容器时却会失败。我们将这种行为作为条件视觉定位的问题进行研究：成功控制所需的视觉目标会随着操作阶段而变化，在更复杂的任务中，还会随着观察到的任务状态而变化。使用带Transformer的动作分块（ACT），我们系统性地引入具有受控颜色和形状相似性的干扰物和容器，并将失败定位到拾取和放置环节。我们发现干扰物敏感性既特定于视觉相似性的类型，也特定于操作阶段。在此诊断的指导下，我们评估了干扰物增强、相位相关注意力正则化和基于外观的视觉提示，作为改善目标选择同时保留控制所需空间信息的补充干预措施。这些干预措施在仿真中和物理UR3e上显著提高了鲁棒性。我们进一步在预训练的视觉-语言-动作策略上检查了相同失败模式，用于状态条件的器械操作任务，其中所观察到的医疗器械状态决定了正确的目的地。这些结果共同表明，即使底层操作技能保持不变，视觉干扰物也可能导致错误的物体或目的地选择，而显式改善目标选择可以显著恢复跨不同视觉运动策略学习范式的性能。

## Abstract
Visuomotor imitation policies can achieve high performance under in-distribution visual conditions yet fail when visually similar objects or receptacles are introduced. We study this behavior as a problem of conditional visual grounding: the visual target required for successful control changes with the manipulation phase and, in more complex tasks, with the observed task state. Using Action Chunking with Transformers (ACT), we systematically introduce distractor objects and receptacles with controlled color and shape similarity and localize failures to picking and placement. We find that distractor sensitivity is specific to both the type of visual similarity and the manipulation stage. Guided by this diagnosis, we evaluate distractor augmentation, phase-dependent attention regularization, and appearance-based visual prompting as complementary interventions for improving target selection while preserving spatial information required for control. These interventions substantially improve robustness in simulation and on a physical UR3e. We further examine the same failure pattern in a pretrained vision-language-action policy on a state-conditioned instrument-handling task, where the observed state of a medical instrument determines the correct destination. Together, the results show that visual distractors can cause incorrect object or destination selection even when the underlying manipulation skill remains intact, and that explicitly improving target selection can substantially recover performance across distinct visuomotor policy-learning regimes.

- **问题定义**：视觉运动模仿策略（visuomotor imitation policies）在受控、干净的环境中能达到很高成功率，但当部署场景中出现视觉上相似的干扰物体或容器时，性能显著下降。这种失败不应简单归因于“策略丧失了操作技能”，而更可能是“策略选择了错误的视觉目标”。
- **核心概念**：论文提出并系统研究 **条件视觉定位（conditional visual grounding）** ——即正确动作依赖于在执行上下文中选出“当前正确”的指代对象（referent）。该相关性并非静态：
  - 对于 ACT（Action Chunking with Transformers）策略，相关性由**操作阶段（phase）**决定：抓取阶段应关注物体，放置阶段应关注容器。
  - 对于预训练视觉-语言-动作（VLA）模型，相关性还由**推断出的任务状态（inferred state）**决定：医疗器械的观测状态决定其正确“去向”（目的地）。
- **研究意图**：区分两类失败——“不知道该不该执行操作”与“保留了执行能力，却对错误实体执行操作”；并进一步定位失败发生在哪个线索（color/shape）、哪个对象类型（object/receptacle）、哪个执行阶段（pick/place）。
- **整体含义**：如果诊断准确，那么可通过轻量级、对象层面的干预来修复目标选择能力，从而在不破坏既有操作技能的前提下显著恢复策略的鲁棒性；且该思路可跨不同策略学习范式（ACT 与 VLA）迁移。

## 2. 论文提出的方法论

### 2.1 诊断框架（Diagnosis）

- 针对 ACT 设计两个分离任务：
  - **Task 1**：物体随机放置，容器固定——用于分离“物体抓取阶段”的定位问题；
  - **Task 2**：物体和容器位置均随机——迫使策略在拾取和放置两个阶段都依赖视觉定位。
- 在测试阶段引入与目标物体/容器在**颜色、形状、或二者均不相近**的干扰物，放入 1～3 个同类别干扰物，并设计“全混合条件”（同时包含颜色匹配物体干扰物与形状匹配容器干扰物等）。
- 为了定位行为失败发生在操作序列的哪个阶段，不使用单一的成功率指标，而是采用**条件概率分解**：
  - P(pick)：正确拾取目标的概率；
  - P(lift | pick)：拾取后正确提起的概率；
  - P(place | pick, lift)：正确拾取和提起后成功放置的概率。
- 通过对**解码器状态**的激活分析，量化 clean 与 full-distractor 条件下的表征漂移、拾取/放置相位结构保持度以及容器位置几何结构。

### 2.2 诊断驱动的干预（Diagnosis-driven interventions）

论文提出三种互补的轻量级干预，并整合为 **ACT-Modified** 架构（如图 1 所示）：

1. **Copy-Paste 数据增强（Distractor augmentation）**  
   在训练阶段，将合成的干扰物体/容器通过图像空间复制粘贴合成到原本干净的演示影像中，从而破坏“外观偶然相关性”，迫使模型不能仅依赖某个物体的表面上出现次数来定位目标。

2. **相位相关注意力正则化（Phase-dependent attention regularization）**  
   监督解码器中的某一个交叉注意力头，令其关注当前任务阶段中相关实体（物体或容器）的掩码，并抑制干扰物掩码的注意力。损失函数为：
   \[
   \mathcal{L}=\mathcal{L}_{ACT}+\lambda_\phi\mathcal{L}_\phi+\lambda_+(1-\langle A,M_\phi\rangle)+\lambda_-\langle A,M_d\rangle
   \]
   其中：
   - \(\mathcal{L}_{ACT}\)：原 ACT 的 CVAE 训练损失；
   - \(\mathcal{L}_\phi\)：相位预测损失；
   - \(A\)：被监督注意力头的归一化注意力；
   - \(M_\phi\)：当前相位相关（目标）掩码；
   - \(M_d\)：干扰物掩码。

3. **基于外观的视觉提示（Appearance-based visual prompting）**  
   提供不含显式全局坐标的目标物体和容器裁剪图，配合相位预测器在推理时根据当前阶段选择正确的提示图。模型必须依据外观而非坐标推断目标身份，同时保留对空间几何信息的感知。
   - 之所以设计为“无位置裁剪”，是为了验证视觉提示的作用在于**目标选择**（identity/appearance），而非直接给出全图坐标。
   - 消融上，将“仅增强”“增强+注意力”“完整 ACT-Modified（含视觉提示）”区分开，以隔离不同组成部分各自的贡献。

### 2.3 VLA 案例研究的诊断-干预流程

- 针对预训练 VLA（π0.5）微调模型，测试状态条件器械操作任务：正确的目的地由医疗器械观测状态决定。
- 通过移除或恢复模型所依赖的 RGB 视觉提示、或者对模型进行目标选择的显式正则化，观察失败是否集中在“选择正确路由目标”的环节。

### 3.1 数据集与场景

- **ACT 仿真任务（Task 1 / Task 2）**：自定义模拟环境，基于 100 条脚本化干净演示（每个任务）训练 ACT，无真实数据集 benchmark。
- **干扰条件设置**：
  - 干扰物的颜色/形状匹配与否分多类；
  - 每类包含 1～3 个干扰物；
  - “full mixed”为最严峻条件（物体与容器竞争同时存在）。
- **物理机器人验证**：UR3e 机械臂，执行 Task 1 和 Task 2 的干净场景与混合干扰场景。

- **提示干预探针（cup-selection probe）**：将目标提示替换为干扰物提示，直接检验提示身份能否因果性地影响闭环目标选择。

- **对比方法**：
  - 标准 ACT；
  - 仅采用数据增强的 ACT；
  - ACT-Modified（增强+注意力正则化+视觉提示，及其子模块消融）；

  - **只提供裁剪、不提供坐标**：清理空间提示后仍能完成任务，说明外观-目标绑定足以支撑定位。
- 物理机器人实验在 UR3e 上重复 10 次/条件，记录拾取与放置的成功次数，用于验证仿真结论的可迁移性。

### 3.3 ACT 模拟与物理实验结果

- **标准 ACT 的失败模式**：
  - 在 Task 1（容器固定）中，当加入形状相似但颜色不同的物体干扰物时，拾取成功率显著下降；而加入颜色相似但形状不同的物体时，失败主要发生在放置阶段。这说明视觉特征匹配是分阶段、分实体类型出现的，而非均匀的全局退化。
  - 在 Task 2（容器随机）中，标准 ACT 的整体成功率在含 3 个混合干扰物时降至极低水平；条件概率分解表明，大部分错误发生在 `pick` 阶段（错抓干扰物体），而 `place` 阶段在正确拾取后的失败相对较小。这支持“目标选择错误”而非“技能丧失”的核心论断。
- **激活分析结果**：
  - 在 clean 条件下，解码器状态对拾取与放置呈现清晰的相位分离结构；
  - 加入 full-distractor 后，标准 ACT 的相位结构发生严重混淆，且容器位置几何信息在状态空间中被弱化；
  - 相比之下，ACT-Modified 的状态空间在 clean 和 full-distractor 之间保持更高的表征一致性，表明视觉提示与正则化共同稳定了对象-阶段绑定。
- **干预效果**：
  - Copy-Paste 数据增强单独使用可恢复部分拾取成功率，但在“全混合”条件下仍不足；
  - 增加相位注意正则化后，容器干扰物的误选明显减少；
  - 完整 ACT-Modified（增强+正则化+视觉提示）在 most challenging full-mixed 条件下，拾取和放置成功率均接近干净场景水平，显示对未见干扰组合的鲁棒性。
  - 消融实验确认：移除视觉提示，全混合条件下成功率下降幅度远大于移除其他组件；提示的主要作用不是提供位置先验，而是重建“当前阶段-正确对象外观”的关联。

### 3.4 VLA 案例研究结果

- π0.5 的默认微调模型在状态条件路由子目标上存在系统性失败：当看不见目标器械的观测状态（如纱布是否已带血、针尖是否已套上保护套）时，模型倾向于选择固定的默认目的地，而非随状态变化的目的地。
- 向该模型提供明确的 RGB 视觉状态提示（例如器械当前状态的裁剪图）后，成功率达到与干净设定相同水平，表明失败源于对“当前状态→正确目的地”的条件映射学习不充分。
- 对错误行为的分类显示：失败几乎全部是“对错误实体的操作正确执行”，而非“不清楚下一步动作”或“执行动作的位姿错误”。这再次验证了条件视觉定位是核心瓶颈。
- 进一步通过显式正则化、要求模型在解码器中首先预测“当前器械状态类别”，再以该类别作为条件选择目的地，能够在不改动网络结构的情况下使模型恢复目标选择能力。

## 4. 讨论与深入分析

### 4.1 为什么标准模仿学习会失败：偶然相关性与“捷径学习”

论文指出，干净演示中目标物体与容器通常占据恒定的相对位置或单一的外观显著性。策略网络容易学到“总是在视觉场景最显著位置抓取颜色/形状固定的物体，再移到固定容器”这类捷径。当测试场景出现竞争性干扰时，网络仍会沿用在训练集上有效的捷径，从而选择错误的实体。这种失败实质上是**表征层面的上下文绑定不足**导致的条件视觉定位崩溃。

### 4.2 干预为何有效：轻量“重新定位”而非“重新训练技能”

三种干预的共同点是强迫模型将“外观身份”作为动态变量来对待：

- Copy-Paste 破坏频率关联，减少捷径机会；
- 相位注意力正则化直接将注意力的“对象选择”与任务阶段绑定；
- 视觉提示则把当前阶段目标外观显式注入解码器，使其在内部表征中构建“状态→目标”的因果依赖。

因此，修复的是视觉目标选择通路，而无需重训动作生成模块。这解释了为何仅轻微修改训练目标与输入格式即可大幅提升鲁棒性，且不需要大规模策略梯度或交互式校正。

### 4.3 任务状态推断与条件视觉定位的统一视角

ACT 的“阶段”和 VLA 的“器械状态”本质上都是**影响动作后果的隐变量**。模仿策略必须在每个决策时刻推断该隐变量，并将其映射为对不同实体/目标的注意力分配。论文的实验证据表明，这种映射是可以被正则化与提示显式化的，且效果优于单纯增加数据多样性。这一统一视角提示：多类模仿学习模型在开放世界中的脆弱性，可能共享“目标条件识别”方面的缺失，而非动作执行方面的缺陷。

### 4.4 局限性与公平性讨论

- 仿真环境为脚本生成，演示数量少、任务简单，不能完全代表真实多人数据中的模态多样性；
- 注意力正则化需要实体掩码或检测框，这在真实部署中需要额外感知模块，论文未讨论其误差对策略的传递影响；
- 视觉提示的裁剪图在物理机器人实验中需要事先知道干扰物位置或使用检测器，与“无额外感知”的设定存在张力；
- VLA 案例仅涉及七步骤任务，且结论基于特定模型与微调方式，能否适用于更大规模的智能体行为尚待验证。

## 5. 结论

- 视觉运动模仿策略在干扰场景下的失败，核心原因是**条件视觉目标选择错误**，而非操作技能丧失。
- 通过分离的成功率分解和表征分析，可以精确定位失败发生在哪个阶段、哪类实体及哪种视觉特征。
- 基于诊断结果提出的 ACT-Modified 与相关干预，能够以轻量化、对象层面的方式恢复策略的鲁棒性，并可迁移到预训练 VLA 模型。
- 论文倡导将“对象的条件识别”作为模仿学习中一个独立、可诊断、可修正的模块，为未来设计更具外在鲁棒性的视觉运动策略提供了新思路。

## 6. 主要贡献总结
