## 摘要
世界动作模型利用预测的未来观测指导动作生成，但基于视觉的预测缺少了决定接触丰富操作成败的局部接触线索。然而，在我们的实验中，将未来触觉观测作为附加视图进行朴素预测仅能恢复可实现增益的三分之一。这一差距反映了时间上的不匹配：预测先于执行，而触觉反馈在执行期间才到达。我们提出TacPAC，将触觉预测转化为实时动作修正。一旦基础模型规划了动作块，TacPAC会缓存该计划所基于的预测接触信息以及计划自身的表示，随后触觉专家将每个新观测到的触觉图像与该缓存对比，以修正尚未执行的动作。因此，反馈是基于计划预期而非孤立地解释，一次修正只需对缓存进行单次遍历，比重生成整个动作块便宜20.7倍。在五个真实机器人任务中，涵盖精密插入、易碎物体处理、物体重定向及长时程操作，TacPAC在每个任务上均取得领先，并将平均成功率从仅视觉基础模型的22%提升到64%。代码可在 https://github.com/LogosRoboticsGroup/TacPAC 获取。

## Abstract
World-action models guide action generation with predicted future observations, but vision-centric predictions miss the local contact cues that decide contact-rich manipulation. However, naively predicting future tactile observations as additional views recovers only a third of the achievable gain in our experiments. This gap reflects a timing mismatch: predictions precede execution, while tactile feedback arrives during it. We introduce TacPAC, which turns tactile prediction into real-time action correction. Once the base model has planned an action chunk, TacPAC caches the predicted contact that plan was conditioned on together with the plan's own representation, and a tactile expert reads each newly observed tactile image against that cache to correct the actions not yet executed. Feedback is thus interpreted against what the plan anticipated rather than in isolation, and one correction is a single pass over that cache, $20.7\times$ cheaper than regenerating the chunk. On five real-robot tasks spanning precision insertion, fragile-object handling, object reorientation, and long-horizon manipulation, TacPAC leads every task and raises the average from 22% for its vision-only base model to 64%. Code is available at https://github.com/LogosRoboticsGroup/TacPAC.

## 一、论文核心问题与研究动机

**核心问题**：
- 接触丰富的操作任务（插拔充电器、抓取薯片、插入扩展卡等）不仅依赖视觉场景几何，还依赖局部接触细节（微小形变、初滑、小位移错位等）。视觉世界动作模型（WAM）对这些细节敏感性不足。
- 将未来触觉观测直接作为额外“视图”加入预测的训练目标，只实现了理论上触觉提升幅度的约 **1/3**。
- 造成这一差距的根本原因是**“时序错位”**：世界动作模型的预测发生在动作执行之前，而触觉反馈到达于执行过程之中；一旦动作块已产生，已有的“计划对于预期接触的依赖”便难以修正。

**整体含义**：触觉预测不是没有被利用，而是没有被用在正确的位置——应在计划已给出、但动作尚未执行完的在线窗口，把实时触觉反馈与计划预期的接触状态**对照比较**，据此修正动作。

## 二、方法论：TacPAC 方法

### 核心思想
- **预测导向的触觉修正**：把触觉预测从“推测未来图像”变成“修正行动的执行时参考”。反馈只有在知道计划期间期望什么样的接触时才有完全意义。
- 基础模型生成动作块后，缓存该动作块生成中所依据的“预测触觉状态键值（KV）”与该动作块的内部表示；随后，由轻量级“触觉专家”在每个新触觉图像到达时，读取当前触觉图像并与缓存对比，输出待执行步骤的增量动作。

### 架构组成
1. **视频专家（Video Expert）** ：预测未来视觉与触觉观测（若将触觉视为附加视图）。对可含视频与触觉的大画布进行条件流动匹配。
2. **动作专家（Action Expert）** ：以视频长度为条件，生成动作块。由混合物变换器（MoT）统一协同，允许动作入token关注视频与动作token。
3. **触觉专家（Tactile Expert）** ：单次前向、与触觉帧同步、将实测触觉图像作为查询，从缓存中读取预测触觉键值和动作键值，输出增量动作。

### 关键技术点
- **缓存机制**：在去噪循环完成之后运行一次干净的流水线前向（flow time τ=0），留下每个层的触觉与动作键值。
  - **只保留触觉与动作键**；因为视觉场景在一个动作块内变化极小，可由两种已存储表示携带。
- **跨偏移修正输入**：设为已有机器人实际执行的动作，填入对应真实状态嵌入，以区分哪些步骤已执行、未执行、待修正。
- **修正不能立即生效**——执行仍在继续，计算修正时有d个动作已交付，因此所有修正从 `m + d` 步后写入，确保不产生倒退与毛刺。
- **每次修正只做单次前向**，路径短，可在高频率下完成，无需重新运行视频专家或去噪。

### 训练两阶段
1. **阶段1（基础模型）** ：联合训练视频专家与动作专家，行动损失与未来帧的视频损失加和。训练全区间 flow-matching，第一阶段动作为计划的动作块。
2. **阶段2（触觉专家）** ：固定阶段1全部参数，对K个偏移量进行采样。用基础模型计划生成动作，但将前m个动作用真实动作替换，训练目标是让触觉专家在网络延迟极限内给出未执行动作的残差。每次训练的每个chunk同时建立多个m，大幅节省计算。

## 六、主要结论与发现

- **主结果**：TacPAC在平均成功率上超过最强基线（**64% vs T-Rex 48%** 和Dream-Tac 45%）。在极端公差插入“充电器插头”与高敏“水果转移”中优势最大（分别80 vs 65，和65 vs 50）。在难度低的薯片转移任务中差距收窄至5%（90 vs 85）。
- **没有感知路径的可替代**：预测而不校正，或只有校正而无预测，都无法代替对方（37% vs 33% avg）。而组合二者的系统达到64%，证明二者具有互补价值。
- **预测-引导的实时校正是本方法核心**：“有其他组件的触觉专家”仅在触觉缓存有无、其余全同时，从47%跳到64%（+17分），证明对比预期接触的修正更有效。
- **时序诊断提供数据理由**：接触跳变阶段持续时间仅占帧时间约4.9%，却占比高达触觉总活动量的18.6%，远大于静默阶段。这类信息出现在“执行之后”，无法凭预期直接被纯预测模型决策影响。
- **效率证明**：触觉专家单次通行用时30.4 ms（约32.9 Hz），接近40倍优于chunk再生628.6 ms。异步显示，仅1.6%调用中动作前进超过1个执行步，几乎可全部覆盖实时反馈的时序。
- **可行性到安全特性**：未出现由校正动作造成的机械突变卡顿。

## 七、优点

### 方法设计亮点
1. **明确的顶层思路**：精确区分“缺乏触觉”“有预测无修正”“有修正无预测”差别，并有内部组件可控实验结果说明不可替代性。
2. **用最简机制实现功能**：在固定缓存上仅做单次转播即可实现校正，使其满足触觉传感器的实际帧率要求，完成高频反馈控制。
3. **创新地构建带时间的输入**：通过“执行与否”识别加入已执行前缀以及未完成后缀，避免操作计划逐步重规划。
4. **提高“预填”利用效率**：同一计划切块可在每一处偏移量进行多次修正训练，节省大量重算成本。
5. **训练数据流水设计**：在阶段2训练中使用模型的自我规划图，确保在推理时遇到的是量化差错训练中的类别，自然衔接“训练—部署路径一致性”。

### 实验设计亮点
1. **公平客观对比**：将所有算法置于相同行动段和动作周期中，且监督重恢复配置，不因结果删掉某任务尝试，避免了“挑成功样本”偏差。
2. **逐层式、设计性消融**：采用系统切断任一路径以隔离贡献的测试，去除触觉缓存和完全空缓存两个预测对读对比实验，测得该关键机制效果是+17个百分点（47→64），高质量支撑主论断。
3. **分解任务难度面**：选取任务覆盖范围（插入、敏感拿取、重定向、准静态操作），使基线也分别暴露各自模型的潜能及瓶颈。
4. **明确反映时间线索**：用293个片段抓拍统计运动规律，解释预测改进有限的“稀疏性”原因，并非凭经验假设推断。

## 八、不足与局限

### 实验局限
1. **任务方差有限，样本数有待增强**：每任务每方案20轮，真实成功率的边际差异（例如5~10个百分点的差异）并不具备显著差异，若无大型测试或配对重数，不足以证明区分度。结果分析中也未提供置信区间与显著性推断。
2. **模型训练无公开规模参数**：难以横向对比训练成本，无法判断是否完全由模型规模、过度手工特征赢取性能。
3. **测试任务是短时程范围**，实际上包含长时操作与切换的新场景未见验证。多阶段序列仅在水果转移（3盘）中有出现，泛化到复杂操纵大程度和整体长期场景的能力尚未评测。
4. **没有包含与SOTA真机其他方案做大规模交叉验证**：与本库比未见使用完整外部VLA预训练权重，虽避免了先验污染，但也局限在自制数据条件下的显示。

### 方法局限
- **依赖大规模真机数据采集与任务定义**；用遥控过程获得真实动作为条件监督触觉专家残差，过程耗时较长，若泛化到新机械臂和新感官，同样流程仍需重新数据构建和训练。
- **环境依赖的局限**：不同环节模型读取触觉须用相同传感器嵌入；虽然在文中指出传感器接口直接使用图像，但无法评价在差异明显触觉设备的迁移效果。
- **残差回归缺陷**：触觉专家可在任意偏移量给出增量，然而修正必须在保留“未执行动作计划”框架内进行。该输出是有限修正，难以处理执行过程中高频改变的任务目标的极端原始误差，可能需靠下一帧chunk重规划来恢复全部决策。
- **阶段标注潜在漏洞**：Q2诊断中利用宽度阈值分析测量手宽，规定接触固定任务范围具有偏差风险——接触和脱离按18帧间隔估计并把行为划在该窗口内，仍可能在较大移动中触碰物体时产生错误标签（文中注明这些方法会削弱检测触觉的能力，倒不是错误导向，但会低估部分接触流），可能升高Q2证明的确定性。
- **校正的时序线性假设**：修正计算所用的d是猜测最近活动窗口延迟，无反馈循环复核，若发生计算超时跳过校正未能获得补偿增益，不过文中数据显示不足2%实际受影响，影响总体结果不大。

## 结论提炼（一句话）
TacPAC的核心观点：将成功世界动作模型中的预测触觉与实际触觉时间差异明确接驳，通过低推高要求的“预期-观察对比”完成执行层校正，让触觉反馈真正在接触丰富操作中发挥作用；本方法在真机多任务中全面证实有效，是值得参考的闭环设计路径。
