## 摘要
我们将动作条件世界建模作为机器人学习中学习可迁移动力学先验的可扩展方法进行研究。通过预训练模型预测动作如何驱动视觉场景演变，所得到的世界模型捕获了超越表象级视频生成的可重用交互动力学。具体而言，我们在带有真实动作标注的大规模机器人操作数据上预训练了一个多视角交互式基础扩散世界模型A2World。我们从两个互补的角度验证了所学习的动力学先验。首先，我们将A2World适配为任务或场景专用的真实世界模拟器A2World-sim，其长时程推演支持基于模拟器的策略评估和可扩展的假设分析，用世界模型推演替代真实机器人推演。其次，从相同的预训练权重出发，我们将A2World适配为视频-动作联合预测模型A2World-policy，在视觉和指令条件下预测动作。跨越仿真基准和真实机器人设置的实验表明，动作条件世界模型预训练产生了可迁移的动力学先验，使以模拟器为中心的机器人学习和以策略为中心的机器人学习都获益。

## Abstract
We study action-conditioned world modeling as a scalable way to learn transferable dynamics priors for robot learning. By pretraining a model to predict how actions drive visual scene evolution, the resulting world model captures reusable interaction dynamics beyond appearance-level video generation. Concretely, we pretrain a multi-view interactive base diffusion world model, A2World, on large-scale robot manipulation data with real action annotations. We validate the learned dynamics priors from two complementary perspectives. First, we adapt A2World into a task- or scene-specialized real-world simulator, A2World-sim, whose long-horizon rollouts support simulator-based policy evaluation and scalable what-if analysis by replacing real-robot rollouts with world model rollouts. Second, starting from the same pretrained weights, we adapt A2World into a video-action joint prediction model, A2World-policy, that predicts actions under visual and instruction conditioning. Experiments across simulation benchmarks and real-robot settings demonstrate that action-conditioned world model pretraining yields transferable dynamics priors that benefit both simulator-centric and policy-centric robot learning.

### 2. 论文提出的方法论
*   **核心思想**：将**动作**视为因果监督信号——无论场景如何变化，动作引起状态改变（例如抓取、推动、释放）的物理规则是共通的。预训练一个动作条件的世界模型，使其编码**动作驱动的可控制动力学**，而非仅仅生成外观逼真的视频。
*   **A2World 基础模型**：
    *   这是一个基于 **DiT（Diffusion Transformer）** 的多视角交互式扩散世界模型。
    *   **输入**：初始帧观测和未来动作块，输出未来的多视角视频。
    *   **动作条件注入**：将动作编码通过 MLP 后，以自适应层归一化（AdaLN）的方式注入每一层 DiT 块的扩散时间步嵌入中。
    *   **多视角生成**：将多个相机视角的潜变量打包到时间维度统一生成，并引入可学习的视角嵌入和**跨视角注意力**模块，确保时空一致性。
    *   **预训练**：在混合机器人数据集上以 EDM 去噪得分匹配目标进行训练，每个 mini-batch 来自单一数据集以避免视角配置冲突。
*   **A2World-sim 模拟器变体**：
    *   从基础模型适配，引入**历史条件机制**。
    *   **位姿引导历史采样**：根据动作的相对位姿变化计算加权弧长，均匀采样关键帧构成紧凑历史，注入模型。
    *   **历史注入**：历史潜变量同时注入交叉注意力（作为上下文）和自注意力（作为键值记忆），使生成过程能参考过去状态。
    *   **自回归推演**：采用 chunk-wise 的方式生成未来帧，并不断更新历史缓存。训练中引入 Self-forcing 策略，周期性地使用模型自己的生成帧作为条件，以提升长序列稳定性。
*   **A2World-policy 策略变体**：
    *   从相同预训练权重初始化，改造为**视频-动作联合预测模型**。
    *   **MoE-like 视频-动作块**：视频和动作潜变量共享自注意力模块以交互，但各自保留独立的 AdaLN 和 MLP 分支（类似混合专家），使动作生成复用视觉动力学先验，同时保留专用建模能力。
    *   **联合扩散**：对视频和动作添加独立噪声，通过一个共享的基础噪声水平缩放，并联合优化去噪目标。
    *   **推理**：使用模态特定的无分类器引导，输入语言指令和初始帧，输出动作序列。
