## 摘要
开放式桌面机器人操作要求系统具备语义理解、精确几何位姿估计和高频动作生成能力。虽然端到端的视觉-语言-动作（VLA）模型擅长语义泛化，但它们往往缺乏针对精细任务的明确几何约束，并且需要昂贵的训练。为弥合高级语义与低级物理执行之间的差距，我们提出OpenSPM，一个由空间位姿记忆和流匹配动作生成模型组成的开放环境空间持久记忆框架。OpenSPM首先利用语义条件3D感知和卡尔曼滤波来跟踪连续的6D位姿。然后从人类演示中提取关键空间位姿，并将其保存为可迁移的、以物体为中心的空间持久记忆条目。在推理过程中，OpenSPM根据自然语言指令检索相关记忆条目，利用SE(3)变换将空间位姿迁移到新场景，并通过轻量级条件流匹配模型生成高频动作块。结合实时本体感知状态反馈和末端残差修正，该系统有效抑制了轨迹误差累积。在十个LIBERO-GOAL任务上评估，OpenSPM达到了85.6%的成功率和1033.3 Hz的等效控制频率，同时仅需极低的推理AI计算能力。广泛的消融实验表明，结构化的空间持久记忆和闭环残差修正在可靠、高频的机器人操作中起着关键作用。

## Abstract
Open-environment tabletop robotic manipulation requires systems to possess semantic understanding, precise geometric pose estimation, and high-frequency action generation. While end-to-end vision-language-action (VLA) models excel at semantic generalization, they often lack explicit geometric constraints for fine-grained tasks and require costly training. To bridge the gap between high-level semantics and low-level physical execution, we propose OpenSPM, an open environment spatial persistent memory framework consisting of spatial pose memory and flow-matching action generation model. OpenSPM first leverages semantically conditioned 3D perception and Kalman filtering to track continuous 6D poses. It then extracts key spatial poses from human demonstrations, keeping them as transferable, object-centric spatial persistent memory entries. During inference, OpenSPM retrieves relevant memory entries in terms of natural language instructions, transfers the spatial poses to new scenes using SE(3) transformations, and generates high-frequency action chunks via a lightweight conditional flow-matching model. Combined with real-time proprioceptive state feedback and terminal residual correction, the system effectively suppresses trajectory error accumulation. Evaluated on ten LIBERO-GOAL tasks, OpenSPM achieves an 85.6% success rate and an equivalent control frequency of 1033.3 Hz, while requiring minimal inference AI computing power. Extensive ablations illustrate that structured spatial persistent memory and closed-loop residual correction play a crucial role in reliable, high-frequency robotic manipulation.

## 2. 方法论

OpenSPM 由离线记忆构建与在线检索‑执行两阶段组成，核心技术模块包括：

- **语义条件 3D 感知与卡尔曼状态估计**
  - 利用多视角语义分割（如 SAM、Qwen）及 SAM 3D 获取物体级分割掩码与三维点云。
  - 将位姿估计建模为含噪状态空间问题，采用卡尔曼滤波对物体平移、速度、方向误差、角速度进行预测‑更新，抑制抖动。
  - 输出连续、尺度一致的 6D 位姿，为后续记忆迁移提供几何基础。

- **关键空间位姿记忆库**
  - 从演示轨迹中提取**阶段性关键空间位姿**（抓取、提升、预对齐、释放等），表示为末端执行器相对于目标物体的 SE(3) 相对位姿。
  - 每个记忆条目包含：语义检索键、语言描述、序列化的相对位姿、阶段标签、置信度与质量分数。
  - 在线推理时，根据自然语言指令和当前场景几何，通过语义匹配与几何可行性打分检索最合适的记忆条目。

- **相对位姿迁移**
  - 利用估计的新场景目标物体位姿 \( T'_o \)，通过相对位姿规则 \( T'_e = T'_o \Delta T_{o \to e} \) 将关键位姿转移到当前世界坐标系。
  - 数学上证明（**定理 1**）：若物体位姿满足 \( T'_o = G T_o \)，则转移后的相对位姿不变，保证局部交互几何的跨场景一致性。

- **条件流匹配动作生成**
  - 在相邻关键位姿间生成短时序动作块（长度 H=5），模型条件包括：当前实际末端位姿、目标关键位姿、相对误差及片段进度。
  - 训练时构建线性插值路径 \( a_\xi = (1-\xi)a_0 + \xi a_{\text{data}} \)，目标速度为 \( a_{\text{data}} - a_0 \)，用均方误差训练条件速度场 \( v_\theta \)。
  - 推理时从高斯噪声开始沿学习到的速度场进行 ODE 积分，生成动作块。模型仅约 240K 参数，单次推理约 4.8 ms。

- **闭环执行与末端残差校正**
  - **段间闭环**：每个动作块起始使用实时本体感知位姿重算条件，避免预规划位姿递推。
  - **末端残差校正**：在抓取、放置等关键节点监测末端与目标位姿的残差 \( r_t \)，若超过阈值则重新生成校正动作块直至收敛。
  - 理论上分析了开环与闭环误差传播公式，证明闭环可抑制段间误差累积。

## 7. 优点

- **分解式架构**创新：将整体操作问题划分为语义 3D 感知、记忆检索、位姿迁移、高频局部动作生成，各模块功能明确、可解释性强。
- **几何可迁移性**：使用对象坐标系下的相对位姿记忆与 SE(3) 变换，使演示经验直接泛化到新物体布局而无需重新训练。
- **轻量高效**：240K 参数流匹配模型达到 1033 Hz 等效频率，推理算力极低，适合实际部署。
- **误差抑制机制**：通过段间重初始化和末端残差校正，从理论和实验上系统解决了动作块拼接的误差传播问题。

## 8. 不足与局限

- **感知依赖强**：整个框架的对齐与迁移质量高度依赖初始分割与 3D 重建精度，对遮挡、视觉相似物体、狭窄支撑区域等复杂情况较为敏感。
- **接触力建模缺失**：目前记忆条目未包含抓取宽度、接触力、障碍距离等信息，难以处理需要力觉反馈的接触约束。

- **额外执行开销**：末端残差校正会增加较多交互步数，虽然响应快速，但在某些时间敏感场景下可能影响节拍。

- **任务泛化边界**：实验限于 LIBERO‑GOAL 的桌面操作，在不同机器人平台或更复杂的动态环境中的适用性有待进一步研究。
